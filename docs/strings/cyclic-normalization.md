# 循环等价类：先规范化，再分组

若一个字符串允许任意次循环移位，那么同一个等价类里没有天然的“原始起点”。直接把输入串当哈希键，会把旋转后的同一对象误分到不同组。稳定的处理方式是：

1. 为每个等价类选定唯一代表；
2. 把原对象转换为这个代表；
3. 对代表做相等判断、哈希或排序。

这种“先规范化、再处理”的思路也适用于无向边端点、分数约分、同构状态压缩等模型。

## 最小循环表示

长度为 $n$ 的字符串 $s$ 有 $n$ 个循环移位。最直接的方法是生成全部移位后取字典序最小值，复制和比较的总成本为 $O(n^2)$。

Booth 算法在双串 $s+s$ 上维护两个候选起点 $i,j$。比较到首个不同字符时：

- 若从 $i$ 开始的候选更大，则 $i$ 到 $i+k$ 的起点都不可能最优；
- 否则同理淘汰 $j$ 到 $j+k$；
- 两个候选都只向右前进，不会回退。

每个起点至多被淘汰一次，因此可在线性时间内得到最小循环表示。

## 为什么可以整段淘汰

设两个候选从偏移 $0$ 到 $k-1$ 完全相同，并在偏移 $k$ 首次不同。若第一个候选较大，那么从它后方不超过 $k$ 的任一起点出发，都会先落入同一段相等字符，再遇到这次已经确定的不利比较；这些起点不可能比第二个候选更小。

淘汰后跳过 `k + 1` 个位置，而不是只移动一格，正是线性复杂度的来源。实现还要保证两个候选起点不同；若推进后相等，就再向后移动一个。

## 多个独立分量怎样合并

若一次操作只会在若干互不影响的分量内部改变顺序，那么全局等价类由各分量的等价类共同决定。对每个分量分别求唯一规范表示，再按固定字段顺序组成签名即可。

LeetCode 3999 中，偶数下标与奇数下标形成两个独立循环：

$$
\operatorname{signature}(s)=
\bigl(|s|,\operatorname{minrot}(s_{\mathrm{even}}),
\operatorname{minrot}(s_{\mathrm{odd}})\bigr).
$$

长度也应进入签名，避免连接两个可变长字段时产生边界歧义。

## 正确性检查

规范化用于分组时，需要同时证明两个方向：

1. **同类同代表**：允许操作不会改变每个独立分量的循环等价类，因此其最小循环表示不变；
2. **同代表同类**：若两个对象的对应分量拥有相同最小循环表示，就能分别旋转到这个共同代表，再逆向旋转到对方。

只证明第一个方向会得到“不会误拆”的必要条件，却不能排除不同对象被误合并。

## 边界与变种

- 空分量的规范表示是空串，仍需由字段边界或长度区分；
- 若允许反转，还要比较最小旋转与反转串的最小旋转；
- 若操作允许任意置换，规范表示退化为排序后的字符多重集合；
- 若只问两个串是否循环等价，可在 `s + s` 中做模式匹配，无须显式求最小代表；
- 动态修改字符会破坏一次性 Booth 扫描，需要哈希、树结构或离线分块维护比较信息；
- 概率哈希可缩短签名，但必须承认碰撞；需要确定性时保留规范串本身。

## 易错检查

- 双串比较是否最多访问一个原串长度；
- 候选推进后是否错误地让 `i == j`；
- 返回的是起点还是已经截取的规范串；
- 多分量签名是否有无歧义的字段边界；
- 是否把必要不变量误写成充分条件；
- 空串、单字符和周期串是否单独验证。
