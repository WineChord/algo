# 题解索引

题解按核心模型组织，而不是按提交日期排列。下面收录的每道题都是可点击的默认折叠条目；展开后可直接查看简要题意、核心思路、复杂度和完整 C++ 实现，也可以进入原题页面。

同一道题在专题页与本索引中复用同一份内容，因此修正思路或代码时只需维护一个权威版本。新增内容遵循[题解写作模板](template.md)。

## 如何使用这份索引

1. 先在对应[知识专题](../guide/roadmap.md)中理解不变量和适用条件；
2. 折叠状态下只看题名，独立尝试从暴力推到可接受复杂度；
3. 展开条目核对关键转化、边界和实现；
4. 关闭详情后重新默写，并为约束变化设计至少一个变种。
