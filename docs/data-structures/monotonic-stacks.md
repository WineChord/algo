# 单调栈：等待未来关闭的边界

单调栈处理一类很具体的问题：元素按顺序到来，某个未来元素第一次满足“更大”或“更小”条件时，才能确定此前若干元素的答案。栈只保留仍可能等待这个未来边界的候选；一旦候选被当前元素支配，就弹出并永久结算。

## 识别信号

常见提问包括：

- 每个位置左侧或右侧第一个更大、严格更大、更小或严格更小的位置；
- 以某个元素为最小值或最大值时能向两侧扩展多远；
- 一个区间何时被未来元素关闭；
- 需要在线追加数据，并在边界出现时立刻结算贡献。

“求区间最大值”本身通常不是单调栈；固定窗口最值更适合单调队列，任意静态区间查询可用稀疏表，动态区间聚合可用线段树。

## 栈中保存什么

通常保存下标而不是只保存数值，因为答案往往还需要距离、宽度或原位置。以寻找右侧第一个严格更小元素为例，维护柱高单调递增的下标栈：

1. 新高度不小于栈顶时，它还不能关闭栈顶，直接入栈；
2. 新高度更小时，反复弹出所有不高于边界要求的候选；
3. 对每个弹出位置，当前下标是右侧第一个满足条件的位置；
4. 弹栈后的新栈顶常常同时给出左侧边界。

不同题目会选择递增或递减、严格或非严格。方向和等号策略必须由题意推导，不能凭模板决定。

## 线性复杂度为什么成立

虽然代码中常有嵌套 `while`，但每个下标只会：

- 入栈一次；
- 出栈至多一次。

因此全部压栈与弹栈次数之和为 $O(n)$。这是按元素记账的摊还分析，不要求每一轮循环都是常数时间。

## 第一个更大：等待天数模型

若栈内温度单调递减，新温度更高时，它会同时成为若干旧位置右侧第一个更高温度。弹出顺序从最近、较低的候选开始，每个位置一旦弹出便永久定稿。

## 最近更矮：柱状图面积模型

固定柱 `i` 为矩形最低高度时，最大宽度由左右第一个严格更矮位置决定。单调栈让右边界在出现时在线结算，弹栈后的栈顶给出左边界。

若左边界下标为 $l$、右边界下标为 $r$，可用宽度是

$$
r-l-1.
$$

末尾追加逻辑哨兵高度 0，可以迫使所有仍在栈中的柱子完成结算；哨兵只参与比较，不能越界访问原数组。

## 相等元素的处理

相等值是否弹出决定边界归属：

- 用 `>=` 弹出：栈内严格递增，相等高度由更靠后的下标继承向右扩展机会；
- 只用 `>` 弹出：栈内非递减，相等高度会同时保留，必须确保至少一个位置最终得到完整宽度；
- 计数题中，相等元素可能需要合并频次，不能只丢弃其中一个。

正确标准不是固定写法，而是每个候选的左右边界是否被不重不漏地结算。设计后应专门验证全相等数组、长平台与交替高低数组。

## 从一维边界迁移到二维

二进制矩阵的最大矩形可以逐行维护连续 1 的高度，把每一行当作一张柱状图，再调用同一个单调栈。二维问题由此降为 $rows$ 次一维问题，总时间 $O(rows\cdot columns)$。

这个迁移成立是因为任意全 1 矩形都有唯一底边；在其底边处理时，每列高度至少等于矩形高度，柱状图算法一定会覆盖它。

若柱宽不全为 1，边界结构仍由高度决定，只需用宽度前缀和把下标差替换为真实宽度。若柱状图首尾相连，可复制一遍处理长度至多为 $n$ 的窗口，但必须额外限制宽度不能超过原数组长度。

## 与相邻结构比较

| 目标 | 结构 | 核心状态 |
| --- | --- | --- |
| 每个位置的首个更大或更小边界 | 单调栈 | 尚未等到边界的候选 |
| 固定滑动窗口的最大或最小值 | 单调队列 | 仍在窗口且可能最优的候选 |
| 动态取全局最小或最大 | 堆 | 当前全局极值 |
| 任意区间聚合与修改 | 线段树 | 可结合的区间摘要 |

单调栈只让当前元素关闭过去候选，不支持任意删除或回看。若更新会改变历史顺序关系，通常需要重算或升级到更强数据结构。

## 易错检查

- 栈保存值还是下标，答案是否需要原位置；
- 寻找的是严格更大还是不小于，严格更小还是不大于；
- 扫描方向是否与所求左右边界一致；
- 弹出后用的是新栈顶还是被弹出的栈顶；
- 宽度是否写成 `right - left - 1`；
- 哨兵下标是否被错误用于访问原数组；
- 面积乘法是否先提升到足够宽的整数类型；
- 全相等、严格递增、严格递减与包含零的输入是否覆盖。

## 学习顺序

1. 先写“右侧第一个严格更大”并解释每次弹栈为何定稿；
2. 改变扫描方向，得到左侧边界；
3. 改变严格性，观察相等平台的归属；
4. 在柱状图中同时利用弹出时的左右边界；
5. 把柱状图迁移到二维矩阵、变宽柱和环形边界。

最终要记住的是候选语义：栈中每个位置仍在等待一个未来边界；当前元素一旦证明它再也不可能等待更晚的第一个边界，就弹出并结算。
