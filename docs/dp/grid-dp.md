# 网格动态规划：方向、邻域与滚动状态

网格只是坐标容器，不自动意味着动态规划。先看合法转移是否始终沿某个拓扑方向前进：若每条边只从上方、左方或其他已处理邻域进入当前格，状态依赖构成 DAG；若允许回头、等待或按路径历史改变边权，则应改用图搜索或扩充状态。

## 从最后一步定义状态

网格最值问题常把状态写成“到达当前格的最优前缀”，局部形状问题则写成“以当前格为某个固定角的最大形状”。两者都要先回答：最后一步或最后一层边界能从哪些已知状态形成？

只允许向右、向下时，到达 $(i,j)$ 的最后一步只能来自上方或左方：

$$
dp_{i,j}=value_{i,j}+\min(dp_{i-1,j},dp_{i,j-1}).
$$

这不是因为网格天然二维，而是因为移动方向给出了拓扑序。按行或按列扫描时，所有依赖都已经求出。

## 形状状态：固定一个角才能局部转移

“最大正方形”若只记录当前格是否为 1，就缺少边长信息；若记录任意正方形，又无法确定唯一转移方向。固定当前格为右下角后，边长只受左、上、左上三个相邻状态限制：

$$
dp_{i,j}=
\begin{cases}
0,&grid_{i,j}=0,\\
1+\min(dp_{i-1,j},dp_{i,j-1},dp_{i-1,j-1}),&grid_{i,j}=1.
\end{cases}
$$

取最小值是必要的：扩成更大的正方形，需要新增的上边、左边与左上内部区域同时完整，任何一侧较短都会成为瓶颈。

## 哨兵与空间压缩

给 DP 表增加一圈零或无穷大哨兵，可以把首行、首列与普通位置统一到同一转移。哨兵值必须匹配目标：

- 求最大可行尺寸时，越界状态常为 0；
- 求最小代价时，不可达方向应为 `INF`，合法起点单独初始化；
- 计数时，空前缀是否为 1 取决于它是否代表一种合法空方案。

若当前行只依赖上一行，可以压成一维。覆盖 `dp[j]` 前要明确每个值的时间层：更新前的 `dp[j]` 是上方，更新后的 `dp[j-1]` 是左方；还需要左上状态时，必须先把旧 `dp[j]` 保存到临时变量。循环方向不是实现细节，而是状态语义的一部分。

## 什么时候应改成图最短路

下面任一变化都会破坏简单的行列拓扑序：

- 允许上下左右移动并可能回到旧格；
- 等待也算一次行动；
- 边权由行动奇偶、钥匙集合或其他路径历史决定；
- 存在传送边或动态障碍。

此时先把影响未来的历史加入状态，再按边权选择 BFS、0-1 BFS 或 Dijkstra。交替行动方向的例子见[奇偶层状态图](../graph/weighted-parity-states.md#alternating-direction-state-graph)。

## 变种与检查表

- 需要恢复路径：保留二维父指针，或在完整距离表上反向判断合法前驱；
- 多次修改单格：一次性滚动数组不足，需要分块、线段树合并转移或离线重算；
- 允许负数但仍为 DAG：拓扑 DP 仍正确，不需要 Dijkstra；
- 统计最优方案数：同时维护最优值与达到该值的计数，相等转移时合并计数；
- 内存受限：先确认覆盖顺序不会读到当前层新值，再压缩维度；
- 形状改变：重新选择能让新增边界局部可验证的锚点，不能直接套正方形递推。
