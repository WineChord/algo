# 零和博弈动态规划：用分差消去行动者身份

双方轮流行动、总收益可加且一方所得就是另一方失去的收益时，不必同时维护两人的绝对得分。更紧凑的状态是：

> 当前行动者从某个局面出发，相对另一方最多能领先多少分。

这个定义自动把“轮到谁”吸收到状态视角中。选择一次行动后，角色交换；因此转移总是“本轮收益减去对手在后继局面能取得的最大分差”。

## 有限取法：后缀分差递推

设 `dp[i]` 为轮到行动者面对后缀 $i$ 时能保证的最大分差。若一次可以拿走前 $k$ 项，取得分数和 $gain(i,k)$，则

$$
dp[i]=\max_k\bigl(gain(i,k)-dp[i+k]\bigr).
$$

减号来自视角切换：后继状态的“当前行动者”已经是本轮对手。枚举所有合法 $k$ 覆盖当前第一步的全部选择；每个后继值又按同一定义最优，所以取最大值就是当前能保证的最优分差。

当每步最多取固定的 $K$ 项时，状态只依赖后面 $K$ 个位置，可把数组压成 $K+1$ 个循环槽。压缩只适用于求胜负或最优分差；恢复完整行动序列还需保存每个位置选取的 $k$，或在得到最优值后重算决策。

### 动作上限也是状态：后缀总和消去对手收益

若本轮可取数量由历史参数 $M$ 决定，位置相同而 $M$ 不同的局面拥有不同动作集合，状态必须扩为 $(i,M)$。当剩余石子总和固定且双方收益互补时，也可让状态记录“当前玩家最多拿多少”；选择 $X$ 堆后，当前玩家最终所得就是当前后缀总和减去对手在 $(i+X,\max(M,X))$ 的最优所得。

这种绝对收益写法与分差写法等价，但后缀和让转移更直观。动作数随 $M$ 增长后，每个状态可能枚举 $O(n)$ 个选择，不能再机械地套用固定 $K$ 的滚动数组。

## 同步博弈：末轮值函数消去巨大的轮数

同步行动且轮数很大时，完整极大极小状态未必是必要的。可以先找一个“若现在就是最后一轮，局面价值是多少”的函数 $F$，再研究双方的早期动作会怎样改变它。

在 Hot Potatoes 中，土豆总数守恒，所以两队得分之和固定，博弈是零和。最后一轮，每条从占用位置指向空位置的合法传递都有明确的跨队收益；把这些局部收益加到当前 Red 得分上，就得到 $F$。进一步逐项计算可证：Red 在早期做任意合法传递都不会增大 $F$，Blue 的早期传递都不会减小 $F$。因此双方在所有早期轮次都保留构成纯策略鞍点，整个 $k$ 轮博弈折叠成“对初态执行一次末轮最优动作”。

这里证明的是存在一种全保留到末轮的最优策略，而不是所有最优策略都唯一。迁移到其他同步博弈时，要重新验证三件事：总收益是否守恒、末轮局部动作是否独立、双方早期动作对 $F$ 是否具有相反方向的单调性；缺一项都不能跳过博弈 DP。

## 与区间博弈的边界

只从一个方向取走元素时，剩余局面由单个后缀下标确定；允许从左右两端取时，状态必须扩为区间 $(l,r)$。若不同玩家拥有不同动作集合，单一“当前行动者视角”可能不再足够，还需加入轮次或玩家类型。

比分差状态适合以下条件：

- 两人收益严格零和；
- 双方都以最终分差为目标并采取最优策略；
- 局面与行动者角色具有对称规则；
- 转移图无环，或能对有环博弈给出额外终止与求解机制。

若目标改为“自己达到阈值即可获胜”、存在合作收益，或平局处理依赖历史，分差可能丢失必要信息，应回到显式的双方收益、胜负状态或一般博弈图。

## 从极大极小到动态规划

暴力搜索展开完整博弈树；相同剩余局面会从多条路径重复出现。记忆化把树折叠成状态 DAG，递推再按依赖的逆序计算。这个过程说明 DP 不是另一套规则，而是对有限极大极小搜索的去重。

对后缀取法题，位置每次严格增加，逆序扫描天然满足依赖。对区间题，区间长度每次缩短，应按长度从小到大计算。若状态可能回到自身，就不能直接套用这两种顺序。

## 检查清单

1. 状态值是否始终从“当前行动者”视角定义？
2. 角色交换处是否使用减号，而不是错误地继续相加？
3. 所有合法第一步是否被完整枚举？
4. 终局分差是否为 0，胜负是否只由最终正、负、零决定？
5. 负分元素是否被正确处理，初值是否使用真正的负无穷？
6. 滚动槽是否可能在本轮提前覆盖仍需读取的后继状态？
