# 极值候选与 Top-K

当答案只依赖最大值、次大值或前 $k$ 个候选时，完整排序往往计算了过多信息。更直接的做法是让扫描状态始终保存“已读前缀中仍可能进入最终答案的元素”，并在新元素到达时淘汰已经不可能影响答案的候选。

本页保留通用模型和选型边界。两个常见乘积模型分别进入：

- [非负两数乘积：从枚举到双极值](pair-product-extrema.md)；
- [有符号乘积与双端极值](signed-product-extrema.md)。

## 识别信号

优先考虑维护极值候选的情形：

- 只求最大若干元素的和、积、阈值或对应位置；
- $k$ 很小而 $n$ 很大；
- 输入以流的形式到达，不需要回看完整历史；
- 需要合并两个区间或两批数据的前若干极值；
- 只关心候选集合，不需要所有元素的完整顺序。

先排除三个常见误判：

1. 允许负数时，最大乘积可能依赖最小值；
2. 动态删除会破坏“淘汰后永不恢复”的流式前提；
3. 若目标依赖相对位置、连续性或频率，只保存数值极值通常不够。

## 核心不变量

记 $T_k(S)$ 为多重集合 $S$ 中按出现次数计算的前 $k$ 大元素。扫描完前缀 $P$ 后，只保存 $T_k(P)$。

新元素 $x$ 到来时，

$$
T_k(P\cup\{x\})=T_k\bigl(T_k(P)\cup\{x\}\bigr).
$$

等式成立是因为：任何已经不在 $T_k(P)$ 中的旧元素，至少被 $k$ 个旧元素压住；只加入一个新元素不会让它重新进入前 $k$。这就是可以永久丢弃其余历史的原因。

重复值按出现位置计数。若最大值出现两次，而 $k\ge2$，两个出现都必须留在状态中；不要先对数值去重。

## 固定且很小的 $k$

用降序数组保存候选。每读到一个数，把它插入正确位置，再截断到长度 $k$。

```cpp
#include <bits/stdc++.h>
using namespace std;
vector<int> topK(const vector<int>& nums, int k) {
  vector<int> best;
  for (int x : nums) {
    auto it = lower_bound(best.begin(), best.end(), x, greater<int>());
    best.insert(it, x);
    if ((int)best.size() > k)
      best.pop_back();
  }
  return best;
}
```

时间 $O(nk)$，空间 $O(k)$。当 $k$ 是二、三或其他很小常数时，代码直接、常数稳定，也便于让状态同时携带下标或其他附加信息。

若 $k=2$，可以把数组展开为两个变量。读到 $x$ 时，若 $x$ 不小于当前最大值，就把旧最大值下放为次大值；否则只尝试更新次大值。详见[非负两数乘积](pair-product-extrema.md)中的完整证明与题目。

## 一般的 $k$：小根堆

当 $k$ 不再适合线性插入时，用大小不超过 $k$ 的小根堆保存当前前 $k$ 大。堆顶是候选中最小、最容易被淘汰的元素。

```cpp
#include <bits/stdc++.h>
using namespace std;
vector<int> topKHeap(const vector<int>& nums, int k) {
  priority_queue<int, vector<int>, greater<int>> q;
  for (int x : nums) {
    if ((int)q.size() < k) {
      q.push(x);
    } else if (x > q.top()) {
      q.pop();
      q.push(x);
    }
  }
  vector<int> ans;
  while (!q.empty()) {
    ans.push_back(q.top());
    q.pop();
  }
  reverse(ans.begin(), ans.end());
  return ans;
}
```

时间 $O(n\log k)$，空间 $O(k)$。只有在需要输出有序前 $k$ 时，最后的整理才额外花费 $O(k\log k)$。

若只做一次离线第 $k$ 大查询，可以用 `nth_element` 在平均 $O(n)$ 时间完成划分；若还要持续接收数据，堆更自然。

## 可合并摘要

前 $k$ 大具有可合并性：

$$
T_k(A\cup B)=T_k\bigl(T_k(A)\cup T_k(B)\bigr).
$$

因此线段树节点、分块摘要或并行计算的局部结果只需保存各自前 $k$ 大。合并两个节点时，从至多 $2k$ 个候选中再取前 $k$。

```cpp
#include <bits/stdc++.h>
using namespace std;
vector<int> mergeTopK(const vector<int>& a, const vector<int>& b, int k) {
  vector<int> ans;
  int i = 0, j = 0;
  while ((int)ans.size() < k && (i < (int)a.size() || j < (int)b.size())) {
    if (j == (int)b.size() || (i < (int)a.size() && a[i] >= b[j])) {
      ans.push_back(a[i++]);
    } else {
      ans.push_back(b[j++]);
    }
  }
  return ans;
}
```

假设 `a`、`b` 已按降序排列且长度都不超过 $k$，合并时间与输出空间均为 $O(k)$。这一性质把“区间查询前若干极值”转化为标准的可结合节点摘要。

## 删除、频率与值域

只保存前 $k$ 的流式状态不支持一般删除：删掉当前候选后，先前被淘汰的元素可能重新进入答案，但它已经不在状态中。

根据约束选择可恢复结构：

| 条件 | 结构 | 更新 | 查询前 $k$ |
| --- | --- | --- | --- |
| 值域很小 | 频率数组 | $O(1)$ | $O(V+k)$ |
| 值域一般、动态增删 | `multiset` 或带计数平衡树 | $O(\log n)$ | $O(k)$ |
| 单点修改、区间询问 | 线段树的 Top-K 摘要 | $O(k\log n)$ | $O(k\log n)$ |
| 只插入、查询第 $k$ 大 | 大小为 $k$ 的小根堆 | $O(\log k)$ | $O(1)$ |

计数与“只求一个答案值”是不同目标。若要求最优方案数量，仅保存极值数值可能丢失组合数，通常还要保存频率。

### 频率本身是有界值域

当目标是前 $k$ 个高频元素时，先用哈希表统计频率。任一元素的频率都在 $[1,n]$，可以把“频率”当作桶下标，从高频桶向低频桶收集；这样不需要对全部不同值排序，时间可降为 $O(n)$。

## 符号与目标函数边界

“取最大的几个元素”只有在替换成更大元素不会让目标变差时才成立。常见判断如下：

- 两个非负因子的乘积对每个因子单调不减，可直接取前二；
- 两个有符号数的最大乘积还可能来自最小的两个数；
- 三个有符号数的最大乘积只需比较“前三大”和“两小一大”；
- 选择一般的 $k$ 个有符号数时，负号奇偶性可能要求同时维护每个选择数量的最大与最小乘积；
- 连续子数组乘积依赖位置，状态应改为“以当前位置结尾的最大/最小乘积”。

这些变化不是实现细节，而是决定候选集合是否仍然充分的模型边界。

## 方法选择

| 需求 | 首选方法 | 时间 | 额外空间 |
| --- | --- | --- | --- |
| 最大值、次大值 | 展开的固定变量 | $O(n)$ | $O(1)$ |
| 固定小 $k$ 的完整候选 | 长度 $k$ 的有序数组 | $O(nk)$ | $O(k)$ |
| 流式前 $k$ 大 | 小根堆 | $O(n\log k)$ | $O(k)$ |
| 一次离线第 $k$ 大 | `nth_element` | 平均 $O(n)$ | 依实现而定 |
| 后续需要完整顺序 | 排序 | $O(n\log n)$ | 依实现而定 |
| 动态删除 | 频率或有序集合 | 依值域而定 | 依结构而定 |
| 区间 Top-K | 可合并摘要 | 预处理与查询依结构而定 | 通常 $O(nk)$ |

面试和竞赛中，优先从“答案到底需要多少个候选”开始：固定两个就展开为变量，一般 $k$ 用堆，需要删除或区间查询时再升级为可恢复、可合并的结构。

## 易错检查

- 重复值是否按不同出现保留；
- `>=` 与 `>` 是否和重复值规则一致；
- 是否在不需要完整顺序时仍然排序全部数据；
- 允许负数后是否仍只保留最大端；
- 删除或区间查询时，摘要是否真的足以恢复答案；
- 乘法是否先提升到足够宽的类型；
- 返回下标时，值相等的字典序规则是否明确。

## 学习路径

1. 在[非负两数乘积](pair-product-extrema.md)中练习从二重枚举、排序到前二扫描；
2. 在[有符号乘积](signed-product-extrema.md)中理解为何负数迫使摘要覆盖数轴两端；
3. 把固定候选升级为堆，再用可合并公式迁移到区间查询；
4. 每次约束变化都重新证明摘要充分性，不要把 Top-K 当作无条件模板。

最终应记住的不是某段更新代码，而是前缀不变量：状态只保留仍可能参与最终答案的候选；一旦删除、符号、连续性或计数目标让被淘汰信息重新变得重要，就必须扩大或更换状态。
