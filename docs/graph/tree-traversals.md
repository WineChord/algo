# 二叉树遍历：顺序、边界与恢复

前序、中序、后序与层序不是四段孤立模板。遍历顺序决定“何时看到根、何时完成子树”，也决定能否从序列恢复结构、能否按层统计以及递归函数应维护什么边界。

## 四种顺序各自提供什么信息

- 前序：根先于左右子树，适合创建节点和向下传递状态；
- 中序：左子树、根、右子树，能在二叉树中分割左右范围；
- 后序：孩子先于父节点，适合合并子树摘要；
- 层序：按深度递增，适合最短层数、每层统计和宽度问题。

递归 DFS 的调用栈天然保存祖先路径；BFS 队列保存同一时间尚未展开的边界。先根据所需输出选择遍历语义，再决定递归还是显式容器。

## 层序遍历：在入队与出队之间固定一层

普通 BFS 会不断把孩子加入队尾。若要输出分层结果，处理一层前先记录当前队列长度 `levelSize`：

1. 本轮只弹出这 `levelSize` 个节点；
2. 它们的孩子统一进入队尾；
3. 本轮结束时，队列恰好只含下一层。

“先固定长度”是层边界不变量。若直接以队列是否为空作为一层循环条件，刚加入的孩子会在同一层被继续处理。

## 层序边界上的结构变换与深度

若一次变换只依赖当前节点及其直接孩子，BFS 可以在节点出队时完成局部修改，再把修改后的孩子加入队列。翻转二叉树就是把每个节点的左右指针交换；各局部交换作用于不同父节点的两条出边，覆盖全部节点后即得到全树镜像。

--8<-- "includes/problems/lc-226.md"

最大深度也可以直接由层序边界计数：每次固定队列中当前层的节点数，完整处理后深度加一。DFS 返回子树深度同样是 $O(n)$；两者分别把额外空间绑定到最大层宽 $w$ 与树高 $h$，应按树形和栈限制选择。

--8<-- "includes/problems/lc-104.md"

## 观察方向优先：每层首次到达

层视图只需要每个深度的一个边界节点。BFS 可以固定层长后取本层最后出队者；DFS 则可以
让遍历顺序直接承载“哪一侧更可见”的语义。求右视图时按“根、右、左”递归，第一次到达
深度 $d$ 的节点一定是该层最右节点；条件 `d == answer.size()` 同时完成首次判定与按层写入。

--8<-- "includes/problems/lc-199.md"

DFS 时间仍为 $O(n)$，额外空间绑定树高 $h$；BFS 空间绑定最大层宽 $w$。若改求左视图，
只需把孩子顺序反转；若要求每层从右数第 $k$ 个节点，单个“首次到达”标记不再充分，应
恢复层内计数或层序容器。

## 中序迭代：祖先栈等待左子树完成

中序遍历的输出时机是“左子树已经完成、右子树尚未开始”。迭代时不断沿左指针压栈；走到空指针后，栈顶就是最深的、左子树已经处理完但自身尚未输出的结点。弹出并输出它，再转向右子树。

每个结点恰好入栈、出栈一次，时间 $O(n)$，空间由树高 $h$ 决定。若要求严格常数辅助空间，可以用 Morris 遍历临时把前驱空右指针接回当前结点，但必须在第二次到达时恢复结构。

--8<-- "includes/problems/lc-94.md"

二叉搜索树要求中序序列严格递增。迭代中序只需保存上一个访问值；每弹出一个结点就与它比较，相等也必须判错。用“值域上下界”递归同样正确，但边界应使用 64 位或可空哨兵，避免在最小、最大整数附近溢出。

--8<-- "includes/problems/lc-98.md"

## 从前序与中序恢复：根与区间必须同步

无重复值时，前序的下一个未使用元素是当前子树根。它在中序序列中的位置把当前区间唯一切成左、右子树：

$$
[L,p-1],\qquad[p+1,R].
$$

递归先构造左子树、再构造右子树，正好与前序的“根、左、右”消费顺序一致。哈希表把中序查根从每层 $O(n)$ 降到期望 $O(1)$；前序指针在每创建一个节点时只前进一次。

--8<-- "includes/problems/lc-105.md"

## 唯一性依赖什么

前序单独不能区分某个唯一孩子在左还是在右；中序提供了左右分割。即便同时给出前序和中序，重复值也会让根在中序中的位置不唯一，需要额外身份、出现次序或候选搜索。

恢复证明通常包含两部分：

1. 构造出的遍历确实等于输入序列；
2. 根位置与左右区间在约束下唯一，所以不存在另一棵不同结构的树。

## 递归边界与迭代替代

- 空区间返回空指针，不消费前序元素；
- 单节点区间创建叶子，左右递归自然为空；
- 退化树的递归深度可达 $O(n)$，平台栈较小时使用显式栈；
- 只需计算遍历结果时，不一定要分配整棵树，可以直接在区间上递归输出。

层序遍历的空间由最大层宽 $w$ 决定；深度优先的额外空间由树高 $h$ 决定。两者时间都可为 $O(n)$，但内存峰值针对的是不同结构。

## 迁移方向

- 之字形层序：层边界不变，只改变每层写入方向；
- 右视图：BFS 每层取最后节点，或右优先 DFS 取首次到达节点；
- 中序与后序恢复：后序从末尾取根，并先构造右子树；
- 前序与后序恢复：一般不唯一，满二叉树等附加条件可恢复；
- 在线修改树结构：静态遍历序列不再足以维护全部信息。
- 局部交换是否会改变接下来应访问的孩子，入队时机是否与变换后的结构一致。
