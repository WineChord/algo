# 图论知识地图

当对象之间存在“连接、依赖、转移或冲突”时，可以把对象建成点、关系建成边。图论的第一步往往不是选算法，而是确定点和边分别代表什么。

## 建图前的五个问题

1. 边有向还是无向？
2. 边是否带权，权值能否为负？
3. 图是稀疏还是稠密？
4. 需要一条路径、最短距离、方案数，还是连通性？
5. 点和边的总规模是多少，是否有多组测试？

同一题可能有多种建图方式。好的建模会让节点数、边数和所求目标同时变得自然。

## 存图

| 方式 | 空间 | 适合 |
| --- | --- | --- |
| 邻接矩阵 | $O(n^2)$ | 稠密图、点数较小、快速查边 |
| 邻接表 | $O(n+m)$ | 大多数稀疏图 |
| 边集 | $O(m)$ | Kruskal、Bellman–Ford、离线处理 |

无向边在邻接表中通常存两次；分析遍历复杂度时仍记作 $O(n+m)$。

## 遍历

### DFS

深度优先搜索适合：

- 枚举连通块；
- 回溯与路径构造；
- 树形递归；
- 时间戳、强连通分量和割点等结构。

递归版本简洁，但链状图可能达到 $O(n)$ 深度。点数很大时考虑显式栈或确认平台栈限制。

### BFS

BFS 按距离分层扩展，因此当所有边权相等时，第一次到达某点即得到最短路。

## 最短路选择

| 边权条件 | 算法 | 复杂度 |
| --- | --- | --- |
| 全部相等 | BFS | $O(n+m)$ |
| 只有 0/1 | 0-1 BFS | $O(n+m)$ |
| 非负权，单源 | Dijkstra + 堆 | $O((n+m)\log n)$ |
| 允许负权，单源 | Bellman–Ford | $O(nm)$ |
| 稀疏图、特殊负权实践 | SPFA | 最坏 $O(nm)$，不可依赖随机表现 |
| 任意两点、点数较小 | Floyd–Warshall | $O(n^3)$ |
| DAG | 按拓扑序松弛 | $O(n+m)$ |

!!! danger "Dijkstra 不能处理负权边"

    Dijkstra 的正确性依赖“当前最小未确定距离以后不会被变小”。负权边会破坏这一不变量，即使图中没有负环也不行。

二值权网格、骑士图路径奇偶和相邻翻转的线性不变量，见 [0-1 权、二分图与操作奇偶](weighted-parity-states.md)。

树上把孩子子树摘要合并给父节点的统一方法，见[树上后序聚合](tree-aggregation.md)。

## DAG 与拓扑排序

拓扑序是有向无环图中满足每条边 $u\to v$ 都让 $u$ 出现在 $v$ 之前的排列。

两种常见实现：

- Kahn：反复取入度为零的点，适合判断环和按层处理；
- DFS 后序：退出节点时入栈，逆序得到拓扑序。

若处理的节点数少于总节点数，图中存在有向环。

## 最小生成树

最小生成树在连通无向带权图中选 $n-1$ 条边，使所有点连通且总权最小。

- **Kruskal**：按边权排序，若两个端点不连通就加入；配合[并查集](../data-structures/index.md#disjoint-set)，复杂度 $O(m\log m)$。
- **Prim**：从点集出发，每次加入连接内外的最小边；堆优化适合稀疏图，矩阵实现适合稠密图。

二者都可由割性质证明：任意一个割上的最轻边可以安全加入某棵最小生成树。

## 连通性

需要区分：

- 无向图连通块；
- 有向图强连通分量；
- 边双连通与桥；
- 点双连通与割点；
- 动态加边或删边下的连通性。

普通 DFS 或并查集只能回答部分问题。看到“删除一条边后是否断开”，应想到桥；看到“互相可达的最大分组”，应想到强连通分量。

## 树是特殊的图

一棵 $n$ 个点的无向连通树恰有 $n-1$ 条边，任意两点之间路径唯一。常见专题：

- 树的直径、重心和子树统计；
- 倍增与最近公共祖先 LCA；
- 树上差分；
- 树形 DP；
- 重链剖分、点分治和 DSU on Tree。

## 常见建模扩展

- 网格：每个格子是点，相邻移动是边；
- 状态搜索：每个合法状态是点，一次操作是边；
- 二分图：对象分成两类，边只跨两侧；
- 分层图：把“已使用特殊机会次数”加入状态；
- 超级源/汇：统一多个起点或终点；
- 拆点：表达点容量、进入与离开成本。

## 易错检查

- 无向边是否双向加入；
- 多组测试是否清空图和访问状态；
- 距离是否会超过 `int`；
- Dijkstra 是否跳过过期堆元素；
- 图是否可能不连通；
- 自环、重边是否影响结论；
- 拓扑排序处理的是全部点还是只有可达点；
- 递归 DFS 是否可能栈溢出。
