??? problem "LeetCode 4010 · 数对的最大强度"
    [打开原题 ↗](https://leetcode.cn/problems/maximize-pair-strength-using-gcd/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」，第 513 场周赛官方 3 分；ZeroTracer 社区估算竞赛分暂未知（检索于 2026-08-03）。

    **题意**：对每个下标对计算两数最小公倍数除以最大公约数，返回最大值。

    **思路**：令 $g=\gcd(a,b)$，强度为 $(a/g)(b/g)$；先除后乘减少中间量，并枚举全部下标对。

    **复杂度**：时间 $O(n^2\log V)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      long long maxPairStrength(vector<int>& nums) {
        long long answer = 0;
        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
          for (int j = i + 1; j < static_cast<int>(nums.size()); ++j) {
            long long common = gcd(nums[i], nums[j]);
            long long strength = 1LL * (nums[i] / common) * (nums[j] / common);
            answer = max(answer, strength);
          }
        }
        return answer;
      }
    };
    ```
