??? problem "LeetCode 739 · 每日温度"
    [打开原题 ↗](https://leetcode.cn/problems/daily-temperatures/){ .problem-source }

    **题意**：对每天的温度，求还需等待多少天才会出现更高温度；不存在则为 `0`。

    **思路**：用单调递减栈保存尚未找到更高温度的下标。当前温度更高时，连续弹栈并计算距离。

    **复杂度**：时间 \(O(n)\)，额外空间 \(O(n)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        vector<int> dailyTemperatures(vector<int>& a) {
            vector<int> ans(a.size()), st;
            for (int i = 0; i < (int)a.size(); ++i) {
                while (!st.empty() && a[st.back()] < a[i]) {
                    ans[st.back()] = i - st.back();
                    st.pop_back();
                }
                st.push_back(i);
            }
            return ans;
        }
    };
    ```
