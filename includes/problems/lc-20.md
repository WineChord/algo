??? problem "LeetCode 20 · 有效的括号"
    [打开原题 ↗](https://leetcode.cn/problems/valid-parentheses/){ .problem-source }

    **难度**：LeetCode 官方「简单」。

    **题意**：判断只含三种括号的字符串是否按正确类型和顺序完全匹配。

    **思路**：左括号入栈；遇到右括号时，它必须与栈顶左括号配对。扫描结束后栈也必须为空。

    **复杂度**：时间 $O(n)$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      bool isValid(string s) {
        stack<char> st;
        for (char c : s) {
          if (c == '(' || c == '[' || c == '{') {
            st.push(c);
            continue;
          }
          if (st.empty()) return false;
          char open = st.top();
          st.pop();
          if ((c == ')' && open != '(') ||
              (c == ']' && open != '[') ||
              (c == '}' && open != '{')) {
            return false;
          }
        }
        return st.empty();
      }
    };
    ```
