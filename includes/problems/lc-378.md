??? problem "LeetCode 378 · 有序矩阵中第 K 小的元素"
    [打开原题 ↗](https://leetcode.cn/problems/kth-smallest-element-in-a-sorted-matrix/){ .problem-source }

    **题意**：矩阵每行、每列均升序，求所有元素中的第 `k` 小值。

    **思路**：二分答案值 `x`。从左下角出发可在线性时间统计 `<=x` 的元素数，再寻找第一个计数至少为 `k` 的值。

    **复杂度**：时间 $O(n\log V)$，其中 $V$ 为值域跨度；额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int kthSmallest(vector<vector<int>>& a, int k) {
            int n = a.size(), l = a[0][0], r = a[n - 1][n - 1];
            auto count = [&](int x) {
                int i = n - 1, j = 0, cnt = 0;
                while (i >= 0 && j < n) {
                    if (a[i][j] <= x) cnt += i + 1, ++j;
                    else --i;
                }
                return cnt;
            };
            while (l < r) {
                int m = l + (r - l) / 2;
                if (count(m) >= k) r = m;
                else l = m + 1;
            }
            return l;
        }
    };
    ```
