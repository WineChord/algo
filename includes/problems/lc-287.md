??? problem "LeetCode 287 · 寻找重复数"
    [打开原题 ↗](https://leetcode.cn/problems/find-the-duplicate-number/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：长度为 $n+1$ 的只读数组取值均在 $[1,n]$，只有一个数重复，要求常量额外空间找出它。

    **思路**：把下标到数组值视为函数图；从下标 0 出发必进入环，重复值恰是环入口，用 Floyd 两阶段定位。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int findDuplicate(vector<int>& nums) {
        int slow = nums[0];
        int fast = nums[0];
        do {
          slow = nums[slow];
          fast = nums[nums[fast]];
        } while (slow != fast);
        slow = nums[0];
        while (slow != fast) {
          slow = nums[slow];
          fast = nums[fast];
        }
        return slow;
      }
    };
    ```
