??? problem "LeetCode 136 · 只出现一次的数字"
    [打开原题 ↗](https://leetcode.cn/problems/single-number/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：数组中恰有一个数出现一次，其余数都出现两次；在线性时间、常数额外空间内找出单次值。

    **思路**：利用异或交换律、结合律及 $x\oplus x=0$，所有成对元素抵消后只剩目标值。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int singleNumber(vector<int>& nums) {
        int answer = 0;
        for (int value : nums) {
          answer ^= value;
        }
        return answer;
      }
    };
    ```
