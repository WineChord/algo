??? problem "LeetCode 337 · 打家劫舍 III"
    [打开原题 ↗](https://leetcode.cn/problems/house-robber-iii/){ .problem-source }

    **题意**：房屋构成二叉树，直接相连的父子节点不能同时偷，求最大金额。

    **思路**：树形 DP。后序遍历为每个节点返回 `{不偷当前节点, 偷当前节点}`：不偷时可取每个孩子两种状态的最大值，偷时只能接两个孩子的“不偷”状态。

    **复杂度**：时间 $O(n)$，递归栈空间 $O(h)$。

    **C++ 实现**

    <!-- compile:skip -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
        pair<int,int> dfs(TreeNode* u){
            if(!u) return {0,0};
            auto [l0,l1]=dfs(u->left);
            auto [r0,r1]=dfs(u->right);
            return {max(l0,l1)+max(r0,r1),u->val+l0+r0};
        }
    public:
        int rob(TreeNode* root) {
            auto [a,b]=dfs(root);
            return max(a,b);
        }
    };
    ```
