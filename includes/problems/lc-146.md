??? problem "LeetCode 146 · LRU 缓存"
    [打开原题 ↗](https://leetcode.cn/problems/lru-cache/){ .problem-source }

    **题意**：实现固定容量缓存，使 `get`、`put` 平均 $O(1)$；容量超限时淘汰最久未使用的键。

    **思路**：双向链表按最近使用时间从新到旧排列，哈希表把键映射到链表节点。命中时用 `splice` 移到表头，超限时删除表尾。

    **复杂度**：每次操作期望 $O(1)$，空间 $O(capacity)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class LRUCache {
      int capacity;
      list<pair<int, int>> order;
      unordered_map<int, list<pair<int, int>>::iterator> position;
      void touch(list<pair<int, int>>::iterator it) {
        order.splice(order.begin(), order, it);
      }
    public:
      LRUCache(int capacity) : capacity(capacity) {}
      int get(int key) {
        auto it = position.find(key);
        if (it == position.end()) return -1;
        touch(it->second);
        return it->second->second;
      }
      void put(int key, int value) {
        auto it = position.find(key);
        if (it != position.end()) {
          it->second->second = value;
          touch(it->second);
          return;
        }
        order.push_front({key, value});
        position[key] = order.begin();
        if ((int)order.size() > capacity) {
          position.erase(order.back().first);
          order.pop_back();
        }
      }
    };
    ```
