??? problem "LeetCode 215 · 数组中的第 K 个最大元素"
    [打开原题 ↗](https://leetcode.cn/problems/kth-largest-element-in-an-array/){ .problem-source }

    **题意**：返回数组按降序排列后的第 `k` 个元素，重复值分别计数。

    **思路**：用 `nth_element` 按降序把第 `k-1` 个位置划分到正确值，无需完整排序。

    **复杂度**：平均时间 \(O(n)\)，额外空间通常为 \(O(\log n)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int findKthLargest(vector<int>& a, int k) {
            nth_element(a.begin(), a.begin() + k - 1, a.end(), greater<int>());
            return a[k - 1];
        }
    };
    ```
