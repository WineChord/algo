??? problem "LeetCode 215 · 数组中的第 K 个最大元素"
    [打开原题 ↗](https://leetcode.cn/problems/kth-largest-element-in-an-array/){ .problem-source }

    **难度**：LeetCode 官方「中等」。

    **题意**：返回数组按降序排列后的第 `k` 个元素，重复值分别计数。

    **思路**：当前官方值域只有 $[-10^4,10^4]$。统计各值频次并从大到小扣减排名，可获得确定性的线性时间；通用比较模型则使用快速选择或 `nth_element`。

    **复杂度**：时间 $O(n+U)$，空间 $O(U)$，其中 $U=20001$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int findKthLargest(vector<int>& nums, int k) {
        const int offset = 10000;
        vector<int> frequency(20001);
        for (int value : nums) ++frequency[value + offset];
        for (int index = 20000; index >= 0; --index) {
          k -= frequency[index];
          if (k <= 0) return index - offset;
        }
        throw logic_error("valid k must produce an answer");
      }
    };
    ```
