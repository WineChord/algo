??? problem "LeetCode 34 · 查找元素的第一个和最后一个位置"
    [打开原题 ↗](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/){ .problem-source }

    **题意**：在升序数组中返回 `target` 的首尾下标；不存在时返回 `[-1,-1]`。

    **思路**：分别求第一个 `>= target` 和第一个 `> target` 的位置，它们构成目标值的半开区间。

    **复杂度**：时间 $O(\log n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        vector<int> searchRange(vector<int>& a, int target) {
            auto first = [&](bool upper) {
                int l = 0, r = a.size();
                while (l < r) {
                    int m = l + (r - l) / 2;
                    if (upper ? a[m] > target : a[m] >= target) r = m;
                    else l = m + 1;
                }
                return l;
            };
            int l = first(false);
            if (l == (int)a.size() || a[l] != target) return vector<int>{-1, -1};
            return vector<int>{l, first(true) - 1};
        }
    };
    ```
