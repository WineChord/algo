??? problem "LeetCode 239 · 滑动窗口最大值"
    [打开原题 ↗](https://leetcode.cn/problems/sliding-window-maximum/){ .problem-source }

    **难度**：LeetCode 官方「困难」。

    **题意**：长度为 `k` 的窗口从左向右滑动，返回每个窗口中的最大值。

    **思路**：双端队列保存仍在窗口内、且对应值单调递减的下标；队首始终是当前最大值。

    **复杂度**：时间 $O(n)$，额外空间 $O(k)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      vector<int> maxSlidingWindow(vector<int>& nums, int k) {
        deque<int> candidates;
        vector<int> answer;
        for (int i = 0; i < (int)nums.size(); ++i) {
          while (!candidates.empty() && candidates.front() <= i - k) {
            candidates.pop_front();
          }
          while (!candidates.empty() && nums[candidates.back()] <= nums[i]) {
            candidates.pop_back();
          }
          candidates.push_back(i);
          if (i + 1 >= k) answer.push_back(nums[candidates.front()]);
        }
        return answer;
      }
    };
    ```
