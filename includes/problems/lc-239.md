??? problem "LeetCode 239 · 滑动窗口最大值"
    [打开原题 ↗](https://leetcode.cn/problems/sliding-window-maximum/){ .problem-source }

    **题意**：长度为 `k` 的窗口从左向右滑动，返回每个窗口中的最大值。

    **思路**：双端队列保存仍在窗口内、且对应值单调递减的下标；队首始终是当前最大值。

    **复杂度**：时间 $O(n)$，额外空间 $O(k)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        vector<int> maxSlidingWindow(vector<int>& a, int k) {
            deque<int> q;
            vector<int> ans;
            for (int i = 0; i < (int)a.size(); ++i) {
                while (!q.empty() && q.front() <= i - k) q.pop_front();
                while (!q.empty() && a[q.back()] <= a[i]) q.pop_back();
                q.push_back(i);
                if (i + 1 >= k) ans.push_back(a[q.front()]);
            }
            return ans;
        }
    };
    ```
