??? problem "LeetCode 486 · 预测赢家"
    [打开原题 ↗](https://leetcode.cn/problems/predict-the-winner/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」，2026-08-01 力扣中国每日一题。

    **题意**：两名玩家轮流从数组两端取数且都采用最优策略，判断先手最终得分是否不少于后手。

    **思路**：区间状态保存轮到行动者能取得的最大净优势；取一端后要减去对手在剩余区间的最优优势。按右端递增、左端递减即可压成一维。

    **复杂度**：时间 $O(n^2)$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      bool predictTheWinner(vector<int>& nums) {
        int n = nums.size();
        vector<int> dp(nums.begin(), nums.end());
        for (int right = 1; right < n; ++right) {
          for (int left = right - 1; left >= 0; --left) {
            dp[left] = max(nums[left] - dp[left + 1], nums[right] - dp[left]);
          }
        }
        return dp[0] >= 0;
      }
    };
    ```
