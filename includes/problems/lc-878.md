??? problem "LeetCode 878 · 第 N 个神奇数字"
    [打开原题 ↗](https://leetcode.cn/problems/nth-magical-number/){ .problem-source }

    **题意**：正整数若能被 $a$ 或 $b$ 整除就是神奇数字，求第 $n$ 个神奇数字并对 $10^9+7$ 取模。

    **思路**：不超过 $x$ 的神奇数字个数由容斥得到：$\lfloor x/a\rfloor+\lfloor x/b\rfloor-\lfloor x/\operatorname{lcm}(a,b)\rfloor$。这个计数随 $x$ 单调，二分第一个计数至少为 $n$ 的位置。

    **复杂度**：时间 $O(\log(n\min(a,b)))$，空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int nthMagicalNumber(int n,int a,int b) {
            long long l=1,r=1LL*n*min(a,b),c=lcm(a,b);
            while(l<r){
                long long m=(l+r)/2;
                if(m/a+m/b-m/c>=n) r=m;
                else l=m+1;
            }
            return l%1000000007;
        }
    };
    ```
