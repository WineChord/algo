??? problem "LeetCode 91 · 解码方法"
    [打开原题 ↗](https://leetcode.cn/problems/decode-ways/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：按 $1\ldots26$ 映射字母，统计数字串的有效解码方法数。

    **思路**：前缀答案只可能由一个合法末位或一个合法两位数转移而来，因此动态规划只保留相邻两个状态。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int numDecodings(string s) {
        int twoBack = 1;
        int oneBack = s[0] == '0' ? 0 : 1;
        for (int i = 1; i < static_cast<int>(s.size()); ++i) {
          int current = s[i] == '0' ? 0 : oneBack;
          int value = (s[i - 1] - '0') * 10 + s[i] - '0';
          if (10 <= value && value <= 26) {
            current += twoBack;
          }
          twoBack = oneBack;
          oneBack = current;
        }
        return oneBack;
      }
    };
    ```
