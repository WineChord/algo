??? problem "LeetCode 628 · 三个数的最大乘积"
    [打开原题 ↗](https://leetcode.cn/problems/maximum-product-of-three-numbers/){ .problem-source }

    **题意**：从整数数组中选择三个不同位置，使三个数的乘积最大。数组允许负数、零和重复值。

    **思路**：答案只可能是“最大的三个数之积”，或“最小的两个数与最大数之积”。一次扫描同时维护三个最大值和两个最小值，比较这两种候选即可。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int maximumProduct(vector<int>& nums) {
        int hi1 = INT_MIN, hi2 = INT_MIN, hi3 = INT_MIN;
        int lo1 = INT_MAX, lo2 = INT_MAX;
        for (int x : nums) {
          if (x >= hi1) {
            hi3 = hi2;
            hi2 = hi1;
            hi1 = x;
          } else if (x >= hi2) {
            hi3 = hi2;
            hi2 = x;
          } else if (x > hi3) {
            hi3 = x;
          }
          if (x <= lo1) {
            lo2 = lo1;
            lo1 = x;
          } else if (x < lo2) {
            lo2 = x;
          }
        }
        return max(hi1 * hi2 * hi3, lo1 * lo2 * hi1);
      }
    };
    ```
