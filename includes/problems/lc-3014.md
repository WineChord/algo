??? problem "LeetCode 3014 · 输入单词需要的最少按键次数 I"
    [打开原题 ↗](https://leetcode.cn/problems/minimum-number-of-pushes-to-type-word-i/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」，2026-07-30 力扣中国每日一题。

    **题意**：把互不相同的字母重新映射到八个数字键，求输入给定单词的最少按键次数。

    **思路**：八个按键各提供一个成本为 1 的槽位，再提供成本为 2、3 的槽位。所有字母频次相同且互不相同，直接优先占用最低成本层。

    **复杂度**：时间 $O(1)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int minimumPushes(string word) {
        int answer = 0;
        for (int i = 0; i < static_cast<int>(word.size()); ++i) {
          answer += i / 8 + 1;
        }
        return answer;
      }
    };
    ```
