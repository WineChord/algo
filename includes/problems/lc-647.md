??? problem "LeetCode 647 · 回文子串"
    [打开原题 ↗](https://leetcode.cn/problems/palindromic-substrings/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：统计字符串中按位置区分的全部回文子串数量。

    **思路**：每个回文子串都有唯一中心；分别枚举字符中心和字符间隙中心，向两侧扩展并逐个计数。

    **复杂度**：时间 $O(n^2)$，额外空间 $O(1)$；Manacher 可把时间降为 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int countSubstrings(string s) {
        int n = s.size();
        int answer = 0;
        for (int center = 0; center < 2 * n - 1; ++center) {
          int left = center / 2;
          int right = left + center % 2;
          while (left >= 0 && right < n && s[left] == s[right]) {
            ++answer;
            --left;
            ++right;
          }
        }
        return answer;
      }
    };
    ```
