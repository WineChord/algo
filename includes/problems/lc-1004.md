??? problem "LeetCode 1004 · 最大连续 1 的个数 III"
    [打开原题 ↗](https://leetcode.cn/problems/max-consecutive-ones-iii/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：最多把 $k$ 个零翻成一，求能得到的最长连续一段。

    **思路**：窗口只记录零的个数；一旦超过预算就移动左端点，始终保持当前右端点对应的最长合法窗口。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:standalone -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int longestOnes(vector<int>& nums, int k) {
        int left = 0;
        int zeros = 0;
        int answer = 0;
        for (int right = 0; right < static_cast<int>(nums.size()); ++right) {
          zeros += nums[right] == 0;
          while (zeros > k) {
            zeros -= nums[left] == 0;
            ++left;
          }
          answer = max(answer, right - left + 1);
        }
        return answer;
      }
    };
    ```
