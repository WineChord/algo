??? problem "LeetCode 746 · 使用最小花费爬楼梯"
    [打开原题 ↗](https://leetcode.cn/problems/min-cost-climbing-stairs/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：每次走一级或两级，踏上台阶要付相应费用，可从下标 0 或 1 开始，求到达楼顶的最小费用。

    **思路**：到达当前位置的最优费用只依赖前两个位置，按最后一步来自哪里递推并滚动保存。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:standalone -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int minCostClimbingStairs(vector<int>& cost) {
        int twoBack = 0;
        int oneBack = 0;
        for (int i = 2; i <= static_cast<int>(cost.size()); ++i) {
          int current = min(oneBack + cost[i - 1], twoBack + cost[i - 2]);
          twoBack = oneBack;
          oneBack = current;
        }
        return oneBack;
      }
    };
    ```
