??? problem "LeetCode 4024：最近的可用无人机"
    [打开原题 ↗](https://leetcode.cn/problems/nearest-available-drone/){ .problem-source }

    **难度与分值**：简单；第 515 场周赛 Q1 官方分值 3；ZeroTracer 社区估算竞赛分未知（2026-08-18）

    **题意**：过滤曼哈顿距离超过自身航程的无人机，在其余候选中返回距离最小、并列时下标最小者。

    **思路**：按下标递增扫描，只在候选可达且距离严格更小时更新；距离相等时保留旧答案，天然实现最小下标决胜。

    **复杂度**：时间 O(n)，额外空间 O(1)。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int nearestDrone(vector<vector<int>>& drones, vector<int>& target) {
        int answer = -1;
        int bestDistance = numeric_limits<int>::max();
        for (int i = 0; i < static_cast<int>(drones.size()); ++i) {
          int distance = abs(drones[i][0] - target[0]) +
              abs(drones[i][1] - target[1]);
          if (distance <= drones[i][2] && distance < bestDistance) {
            bestDistance = distance;
            answer = i;
          }
        }
        return answer;
      }
    };
    ```
