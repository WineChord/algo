??? problem "LeetCode 76 · 最小覆盖子串"
    [打开原题 ↗](https://leetcode.cn/problems/minimum-window-substring/){ .problem-source }

    **题意**：在字符串 `s` 中找包含 `t` 全部字符及其出现次数的最短子串。

    **思路**：右端扩张并减少缺失计数；窗口满足要求后不断收缩左端，同时记录最短答案。`need[c]` 表示当前仍缺多少个字符 `c`。

    **复杂度**：时间 $O(|s|+|t|)$，字符集固定时额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        string minWindow(string s, string t) {
            array<int, 128> need{};
            for (char c : t) ++need[c];
            int missing = t.size(), l = 0, best = INT_MAX, start = 0;
            for (int r = 0; r < (int)s.size(); ++r) {
                if (need[s[r]] > 0) --missing;
                --need[s[r]];
                while (!missing) {
                    if (r - l + 1 < best) best = r - l + 1, start = l;
                    if (++need[s[l++]] > 0) ++missing;
                }
            }
            return best == INT_MAX ? "" : s.substr(start, best);
        }
    };
    ```
