??? problem "LeetCode 3731 · 找出缺失的元素"
    [打开原题 ↗](https://leetcode.cn/problems/find-missing-elements/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」，2026-08-04 力扣中国每日一题。

    **题意**：数组元素互异，最小值与最大值保留；按递增顺序返回二者之间未出现在数组中的所有整数。

    **思路**：记录每个输入值是否出现，再按最小值到最大值顺序扫描并输出缺失值；扫描顺序天然保证答案递增。

    **复杂度**：时间 $O(n+R)$，空间 $O(R)$，其中 $R=\max(nums)-\min(nums)+1$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      vector<int> findMissingElements(vector<int>& nums) {
        int minimum = *min_element(nums.begin(), nums.end());
        int maximum = *max_element(nums.begin(), nums.end());
        array<bool, 101> present{};
        for (int value : nums) {
          present[value] = true;
        }
        vector<int> answer;
        for (int value = minimum; value <= maximum; ++value) {
          if (!present[value]) {
            answer.push_back(value);
          }
        }
        return answer;
      }
    };
    ```
