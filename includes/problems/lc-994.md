??? problem "LeetCode 994 · 腐烂的橘子"
    [打开原题 ↗](https://leetcode.cn/problems/rotting-oranges/){ .problem-source }

    **题意**：每分钟，腐烂橘子会使四方向相邻的新鲜橘子腐烂；求全部新鲜橘子腐烂所需的最少分钟数，无解返回 \(-1\)。

    **思路**：所有初始腐烂橘子等价于同一时刻的多个源点。把它们一起入队做多源 BFS，逐层扩散并统计剩余新鲜橘子；最后仍有新鲜橘子即无解。

    **复杂度**：时间 \(O(mn)\)，空间 \(O(mn)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int orangesRotting(vector<vector<int>>& grid) {
            int m=grid.size(),n=grid[0].size(),fresh=0,ans=0;
            queue<pair<int,int>> q;
            for(int i=0;i<m;i++) for(int j=0;j<n;j++) if(grid[i][j]==2) q.push({i,j}); else fresh+=grid[i][j]==1;
            int d[5]={-1,0,1,0,-1};
            while(fresh&&!q.empty()){
                for(int k=q.size();k--;){
                    auto [x,y]=q.front();
                    q.pop();
                    for(int t=0;t<4;t++){
                        int nx=x+d[t],ny=y+d[t+1];
                        if(nx>=0&&nx<m&&ny>=0&&ny<n&&grid[nx][ny]==1) grid[nx][ny]=2,fresh--,q.push({nx,ny});
                    }
                }
                ans++;
            }
            return fresh?-1:ans;
        }
    };
    ```
