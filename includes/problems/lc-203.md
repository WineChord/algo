??? problem "LeetCode 203 · 移除链表元素"
    [打开原题 ↗](https://leetcode.cn/problems/remove-linked-list-elements/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：删除单链表中值等于目标值的全部节点并返回新表头。

    **思路**：虚拟头节点把删除原表头统一为删除普通后继；只在保留当前后继时推进前驱。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode-list -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      ListNode* removeElements(ListNode* head, int val) {
        ListNode dummy{0, head};
        ListNode* previous = &dummy;
        while (previous->next) {
          if (previous->next->val == val) {
            previous->next = previous->next->next;
          } else {
            previous = previous->next;
          }
        }
        return dummy.next;
      }
    };
    ```
