??? problem "LeetCode 3622：判断整除性"
    [打开原题 ↗](https://leetcode.cn/problems/check-divisibility-by-digit-sum-and-product/){ .problem-source }

    **难度与竞赛分**：简单；第 459 场周赛 Q1；ZeroTracer 社区估算竞赛分 1148.94（2026-08-22）

    **题意**：计算正整数的十进制数字和与数字积，判断原数能否被两者之和整除。

    **思路**：保留原数，用副本反复除十取余，同时累加数字和、累乘数字积；最后检查 `n % (sum + product) == 0`。数字 0 会把积变为 0，但正数的数字和保证除数非零。

    **复杂度**：时间 $O(\log n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      bool checkDivisibility(int n) {
        int value = n;
        int sum = 0;
        int product = 1;
        while (value > 0) {
          int digit = value % 10;
          sum += digit;
          product *= digit;
          value /= 10;
        }
        return n % (sum + product) == 0;
      }
    };
    ```
