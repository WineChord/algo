??? problem "LeetCode 200 · 岛屿数量"
    [打开原题 ↗](https://leetcode.cn/problems/number-of-islands/){ .problem-source }

    **题意**：在由陆地 `1` 和水域 `0` 组成的网格中，四方向相连的陆地构成一座岛，求岛屿数量。

    **思路**：逐格扫描；每遇到一块尚未访问的陆地，答案加一，并从它出发 DFS 把整座岛改成水域。一次搜索恰好消去一个连通分量。

    **复杂度**：时间 \(O(mn)\)，递归栈空间最坏 \(O(mn)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
        int m,n;
        void dfs(vector<vector<char>>& a,int x,int y){
            if(x<0||x==m||y<0||y==n||a[x][y]!='1') return;
            a[x][y]='0';
            dfs(a,x+1,y);
            dfs(a,x-1,y);
            dfs(a,x,y+1);
            dfs(a,x,y-1);
        }
    public:
        int numIslands(vector<vector<char>>& grid) {
            m=grid.size(),n=grid[0].size();
            int ans=0;
            for(int i=0;i<m;i++) for(int j=0;j<n;j++) if(grid[i][j]=='1') ans++,dfs(grid,i,j);
            return ans;
        }
    };
    ```
