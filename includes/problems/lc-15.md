??? problem "LeetCode 15 · 三数之和"
    [打开原题 ↗](https://leetcode.cn/problems/3sum/){ .problem-source }

    **题意**：给定整数数组，找出所有元素和为 \(0\) 且互不重复的三元组。

    **思路**：排序后枚举最小元素，用相向双指针寻找另外两个数；根据三数之和移动指针，并在三个位置都跳过重复值。

    **复杂度**：时间 \(O(n^2)\)，除答案外额外空间 \(O(1)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        vector<vector<int>> threeSum(vector<int>& a) {
            sort(a.begin(), a.end());
            vector<vector<int>> ans;
            int n = a.size();
            for (int i = 0; i < n && a[i] <= 0; ++i) {
                if (i && a[i] == a[i - 1]) continue;
                int l = i + 1, r = n - 1;
                while (l < r) {
                    long long s = 1LL * a[i] + a[l] + a[r];
                    if (s < 0) ++l;
                    else if (s > 0) --r;
                    else {
                        ans.push_back({a[i], a[l], a[r]});
                        int x = a[l], y = a[r];
                        while (l < r && a[l] == x) ++l;
                        while (l < r && a[r] == y) --r;
                    }
                }
            }
            return ans;
        }
    };
    ```
