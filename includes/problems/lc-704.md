??? problem "LeetCode 704 · 二分查找"
    [打开原题 ↗](https://leetcode.cn/problems/binary-search/){ .problem-source }

    **题意**：在升序数组中查找 `target`，存在则返回下标，否则返回 `-1`。

    **思路**：在半开区间 \([l,r)\) 中寻找第一个 `>= target` 的位置，结束后再检查该位置是否等于目标。

    **复杂度**：时间 \(O(\log n)\)，额外空间 \(O(1)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int search(vector<int>& a, int target) {
            int l = 0, r = a.size();
            while (l < r) {
                int m = l + (r - l) / 2;
                if (a[m] >= target) r = m;
                else l = m + 1;
            }
            return l < (int)a.size() && a[l] == target ? l : -1;
        }
    };
    ```
