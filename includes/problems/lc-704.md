??? problem "LeetCode 704 · 二分查找"
    [打开原题 ↗](https://leetcode.cn/problems/binary-search/){ .problem-source }

    **难度**：LeetCode 官方「简单」。

    **题意**：在升序数组中查找 `target`，存在则返回下标，否则返回 `-1`。

    **思路**：在半开区间 $[l,r)$ 中寻找第一个 `>= target` 的位置，结束后再检查该位置是否等于目标。

    **复杂度**：时间 $O(\log n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int search(vector<int>& nums, int target) {
        int left = 0, right = nums.size();
        while (left < right) {
          int middle = left + (right - left) / 2;
          if (nums[middle] >= target) right = middle;
          else left = middle + 1;
        }
        return left < (int)nums.size() && nums[left] == target ? left : -1;
      }
    };
    ```
