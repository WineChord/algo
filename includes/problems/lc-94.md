??? problem "LeetCode 94 · 二叉树的中序遍历"
    [打开原题 ↗](https://leetcode.cn/problems/binary-tree-inorder-traversal/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：按左子树、根、右子树的顺序返回二叉树结点值。

    **思路**：显式栈保存等待左子树完成的祖先链；左路压到底后弹出根，再转向右子树。

    **复杂度**：时间 $O(n)$，额外空间 $O(h)$。

    **C++ 实现**

    <!-- compile:leetcode-tree -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      vector<int> inorderTraversal(TreeNode* root) {
        vector<int> order;
        stack<TreeNode*> pending;
        TreeNode* current = root;
        while (current != nullptr || !pending.empty()) {
          while (current != nullptr) {
            pending.push(current);
            current = current->left;
          }
          current = pending.top();
          pending.pop();
          order.push_back(current->val);
          current = current->right;
        }
        return order;
      }
    };
    ```
