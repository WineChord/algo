??? problem "LeetCode 3345 · 最小可整除数位乘积 I"
    [打开原题 ↗](https://leetcode.cn/problems/smallest-divisible-digit-product-i/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」，2026-08-06 力扣中国每日一题。

    **题意**：求不小于 $n$ 的最小整数，使其十进制数位乘积能被 $t$ 整除。

    **思路**：从 $n$ 递增检查；接下来至多九步必遇到末位为零的整数，其数位积为零，故搜索有严格常数上界。

    **复杂度**：最多检查 10 个候选，时间 $O(\log n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
      int digitProduct(int value) {
        int product = 1;
        while (value > 0) {
          product *= value % 10;
          value /= 10;
        }
        return product;
      }
    public:
      int smallestNumber(int n, int t) {
        for (int value = n; value <= n + 9; ++value) {
          if (digitProduct(value) % t == 0) {
            return value;
          }
        }
        return -1;
      }
    };
    ```
