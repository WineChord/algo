??? problem "LeetCode 124 · 二叉树中的最大路径和"
    [打开原题 ↗](https://leetcode.cn/problems/binary-tree-maximum-path-sum/){ .problem-source }

    **难度与分值**：LeetCode 官方「困难」。

    **题意**：求二叉树中任意一条至少含一个节点、节点不重复的路径的最大节点值之和。

    **思路**：后序递归返回从当前节点向下延伸的一条最大单支贡献；在当前节点把左右两个正贡献同时接入，更新不能再向父节点延伸的全局答案。

    **复杂度**：时间 $O(n)$，递归额外空间 $O(h)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    struct TreeNode {
      int val;
      TreeNode* left;
      TreeNode* right;
    };
    class Solution {
      int answer;
      int gain(TreeNode* node) {
        if (node == nullptr) {
          return 0;
        }
        int left = max(0, gain(node->left));
        int right = max(0, gain(node->right));
        answer = max(answer, node->val + left + right);
        return node->val + max(left, right);
      }
    public:
      int maxPathSum(TreeNode* root) {
        answer = numeric_limits<int>::min();
        gain(root);
        return answer;
      }
    };
    ```
