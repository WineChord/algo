??? problem "LeetCode 142 · 环形链表 II"
    [打开原题 ↗](https://leetcode.cn/problems/linked-list-cycle-ii/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：若单链表有环，返回第一个入环节点，否则返回空指针，且不能修改链表。

    **思路**：快慢指针先在环内相遇；随后一指针回到表头，两者同速前进，下一次相遇点恰为环入口。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode-list -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      ListNode* detectCycle(ListNode* head) {
        ListNode* slow = head;
        ListNode* fast = head;
        do {
          if (!fast || !fast->next) {
            return nullptr;
          }
          slow = slow->next;
          fast = fast->next->next;
        } while (slow != fast);
        slow = head;
        while (slow != fast) {
          slow = slow->next;
          fast = fast->next;
        }
        return slow;
      }
    };
    ```
