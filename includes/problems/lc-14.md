??? problem "LeetCode 14 · 最长公共前缀"
    [打开原题 ↗](https://leetcode.cn/problems/longest-common-prefix/){ .problem-source }

    **难度**：LeetCode 官方「简单」。

    **题意**：返回字符串数组的最长公共前缀；不存在公共前缀时返回空串。

    **思路**：逐列检查第一个字符串的字符。只有当所有字符串在该位置存在且字符相同，这一列才能加入公共前缀；第一次失败后，任何更长前缀都不可能成立。

    **复杂度**：时间 $O(S)$，其中 $S$ 是检查过的字符总数；返回值之外额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      string longestCommonPrefix(vector<string>& strs) {
        for (int i = 0; i < (int)strs[0].size(); ++i) {
          char expected = strs[0][i];
          for (int j = 1; j < (int)strs.size(); ++j) {
            if (i == (int)strs[j].size() || strs[j][i] != expected) {
              return strs[0].substr(0, i);
            }
          }
        }
        return strs[0];
      }
    };
    ```
