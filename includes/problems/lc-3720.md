??? problem "LeetCode 3720：大于目标字符串的最小字典序排列"
    [打开原题 ↗](https://leetcode.cn/problems/lexicographically-smallest-permutation-greater-than-target/){ .problem-source }

    **难度与竞赛分**：中等；第 472 场周赛 Q3 官方分值 5；ZeroTracer 社区估算竞赛分 1958.15（2026-08-27）

    **题意**：重排 `s` 的全部字符，求严格大于 `target` 的字典序最小排列；不存在时返回空字符串。

    **思路**：先用字符频次尽量匹配 `target` 前缀。当前位无法增大时，恢复上一位并向左回退；在最靠右的可行枢轴选择最小可用的更大字符，再把其余字符升序填入后缀。

    **复杂度**：时间 $O(26n)=O(n)$，额外空间 $O(26)$，返回值占 $O(n)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      string lexGreaterPermutation(string s, string target) {
        array<int, 26> count{};
        for (char c : s)
          ++count[c - 'a'];
        int n = static_cast<int>(s.size());
        int i = 0;
        while (i < n && count[target[i] - 'a'] > 0) {
          --count[target[i] - 'a'];
          ++i;
        }
        while (true) {
          if (i < n) {
            for (int c = target[i] - 'a' + 1; c < 26; ++c) {
              if (count[c] == 0)
                continue;
              string answer = target.substr(0, i);
              answer.push_back(static_cast<char>('a' + c));
              --count[c];
              for (int x = 0; x < 26; ++x)
                answer.append(count[x], static_cast<char>('a' + x));
              return answer;
            }
          }
          if (i == 0)
            break;
          --i;
          ++count[target[i] - 'a'];
        }
        return "";
      }
    };
    ```
