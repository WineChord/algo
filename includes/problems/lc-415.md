??? problem "LeetCode 415 · 字符串相加"
    [打开原题 ↗](https://leetcode.cn/problems/add-strings/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：不把完整输入转成整数，计算两个非负十进制数字字符串之和。

    **思路**：从低位向高位逐列相加，尾部追加当前数位并维护唯一进位，最后反转答案。

    **复杂度**：时间 $O(n+m)$，除答案外额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      string addStrings(string num1, string num2) {
        int i = static_cast<int>(num1.size()) - 1;
        int j = static_cast<int>(num2.size()) - 1;
        int carry = 0;
        string answer;
        answer.reserve(max(num1.size(), num2.size()) + 1);
        while (i >= 0 || j >= 0 || carry) {
          int sum = carry;
          if (i >= 0) {
            sum += num1[i--] - '0';
          }
          if (j >= 0) {
            sum += num2[j--] - '0';
          }
          answer.push_back(static_cast<char>('0' + sum % 10));
          carry = sum / 10;
        }
        reverse(answer.begin(), answer.end());
        return answer;
      }
    };
    ```
