??? problem "LeetCode 204 · 计数质数"
    [打开原题 ↗](https://leetcode.cn/problems/count-primes/){ .problem-source }

    **题意**：统计严格小于 $n$ 的质数个数。

    **思路**：埃氏筛从 $2$ 开始扫描；遇到尚未被标记的数就是质数，再从 $i^2$ 起标记它的倍数。更小的倍数已经被更小质因子处理过。

    **复杂度**：时间 $O(n\log\log n)$，空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int countPrimes(int n) {
            vector<char> comp(n);
            int ans=0;
            for(int i=2;i<n;i++) if(!comp[i]){
                ans++;
                if(1LL*i*i<n) for(int j=i*i;j<n;j+=i) comp[j]=1;
            }
            return ans;
        }
    };
    ```
