??? problem "LeetCode 3517 · 最小回文排列 I"
    [打开原题 ↗](https://leetcode.cn/problems/smallest-palindromic-rearrangement-i/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」，第 445 场周赛官方分值 $4$；[ZeroTracer](https://zerotrac.github.io/leetcode_problem_rating/) 社区估算竞赛分 $1357.0$（检索于 2026-07-28）。

    **题意**：给定一个已经是回文串的小写字符串，重排全部字符，返回字典序最小的回文排列。

    **思路**：回文由左半边、至多一个中心字符和左半边的镜像唯一决定。左半边必须包含每个字符频次的一半；按字符升序直接输出这个多重集合，便得到最小左半边与最小完整回文。

    **复杂度**：时间 $O(n+\sigma)=O(n)$，额外工作空间 $O(\sigma)=O(1)$，其中 $\sigma=26$；返回值占 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      string smallestPalindrome(string s) {
        array<int, 26> cnt{};
        for (char c : s) ++cnt[c - 'a'];
        string left;
        left.reserve(s.size() / 2);
        char mid = 0;
        for (int c = 0; c < 26; ++c) {
          left.append(cnt[c] / 2, char('a' + c));
          if (cnt[c] % 2 == 1) mid = char('a' + c);
        }
        string ans = left;
        if (mid != 0) ans.push_back(mid);
        for (auto it = left.rbegin(); it != left.rend(); ++it) ans.push_back(*it);
        return ans;
      }
    };
    ```
