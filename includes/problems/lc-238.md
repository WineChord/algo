??? problem "LeetCode 238 · 除了自身以外数组的乘积"
    [打开原题 ↗](https://leetcode.cn/problems/product-of-array-except-self/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：不使用除法，为每个位置返回除自身以外所有元素的乘积。

    **思路**：先把每个位置左侧元素之积写入输出数组，再从右向左用一个滚动后缀积乘入，避免两张辅助表。

    **复杂度**：时间 $O(n)$；除输出数组外，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:standalone -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      vector<int> productExceptSelf(vector<int>& nums) {
        int n = nums.size();
        vector<int> answer(n, 1);
        for (int i = 1; i < n; ++i) {
          answer[i] = answer[i - 1] * nums[i - 1];
        }
        int suffix = 1;
        for (int i = n - 1; i >= 0; --i) {
          answer[i] *= suffix;
          suffix *= nums[i];
        }
        return answer;
      }
    };
    ```
