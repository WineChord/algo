??? problem "LeetCode 49 · 字母异位词分组"
    [打开原题 ↗](https://leetcode.cn/problems/group-anagrams/){ .problem-source }

    **题意**：把包含相同字符多重集合、仅排列不同的字符串归入同一组。

    **思路**：统计每个字符串的 26 维字母频次并编码为带分隔符的无歧义键；键相同当且仅当两串互为字母异位词。

    **复杂度**：设总字符数为 $S$、字符串数为 $n$，平均时间 $O(S+26n)$，除输出外空间 $O(26n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
      string signature(const string& s) {
        array<int, 26> count{};
        for (char c : s) ++count[c - 'a'];
        string key;
        for (int value : count) key += "#" + to_string(value);
        return key;
      }
    public:
      vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> groups;
        for (string& s : strs) groups[signature(s)].push_back(s);
        vector<vector<string>> answer;
        answer.reserve(groups.size());
        for (auto& [key, group] : groups) answer.push_back(std::move(group));
        return answer;
      }
    };
    ```
