??? problem "LeetCode 494 · 目标和"
    [打开原题 ↗](https://leetcode.cn/problems/target-sum/){ .problem-source }

    **题意**：给每个非负整数添加正号或负号，求最终表达式等于 `target` 的方案数。

    **思路**：设取正号的元素和为 \(P\)，全部元素和为 \(S\)，则 \(P-(S-P)=target\)，即 \(P=(S+target)/2\)。检查范围和奇偶性后，转成“选出若干元素恰好组成 \(P\)”的 0/1 背包计数。

    **复杂度**：时间 \(O(nP)\)，空间 \(O(P)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int findTargetSumWays(vector<int>& nums,int target) {
            int s=accumulate(nums.begin(),nums.end(),0);
            if(abs(target)>s||((s+target)&1)) return 0;
            int p=(s+target)/2;
            vector<int> dp(p+1);
            dp[0]=1;
            for(int x:nums) for(int j=p;j>=x;j--) dp[j]+=dp[j-x];
            return dp[p];
        }
    };
    ```
