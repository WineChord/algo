??? problem "LeetCode 3998 · 使用子序列排序转换二进制字符串"
    [打开原题 ↗](https://leetcode.cn/problems/transform-binary-string-using-subsequence-sort/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」，第 511 场周赛官方分值 $5$；[ZeroTracer](https://zerotrac.github.io/leetcode_problem_rating/) 社区估算竞赛分 $1862.4$（检索于 2026-07-28）。

    **题意**：可反复选择原二进制串的任意子序列并按非降序放回。对每个含 `0`、`1`、`?` 的模式串，判断能否替换问号，使所得串可由原串变换得到。

    **思路**：对子序列排序等价于不断执行 `10 -> 01`，因此 1 只能向右移动。目标串必须与原串的 1 总数相同，且每个前缀的 1 数不能超过原串对应前缀。对一个模式固定所需的问号 1 数后，把这些 1 尽量放在最右侧，便同时最小化所有前缀；检查这个支配最优的补全即可。

    **复杂度**：设原串长度为 $n$、模式数为 $m$，时间 $O(nm)$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      vector<bool> transformStr(string s, vector<string>& strs) {
        int n = s.size();
        vector<int> sourcePrefix(n);
        int sourceOnes = 0;
        for (int i = 0; i < n; ++i) {
          sourceOnes += s[i] == '1';
          sourcePrefix[i] = sourceOnes;
        }
        vector<bool> answer;
        answer.reserve(strs.size());
        for (const string& pattern : strs) {
          int fixedOnes = count(pattern.begin(), pattern.end(), '1');
          int questions = count(pattern.begin(), pattern.end(), '?');
          int needed = sourceOnes - fixedOnes;
          if (needed < 0 || needed > questions) {
            answer.push_back(false);
            continue;
          }
          int prefixOnes = 0;
          int remainingQuestions = questions;
          bool possible = true;
          for (int i = 0; i < n; ++i) {
            if (pattern[i] == '1') {
              ++prefixOnes;
            } else if (pattern[i] == '?') {
              if (needed > remainingQuestions - 1) {
                ++prefixOnes;
                --needed;
              }
              --remainingQuestions;
            }
            if (prefixOnes > sourcePrefix[i]) possible = false;
          }
          answer.push_back(possible);
        }
        return answer;
      }
    };
    ```
