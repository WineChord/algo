??? problem "LeetCode 45 · 跳跃游戏 II"
    [打开原题 ↗](https://leetcode.cn/problems/jump-game-ii/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：每个位置给出最远向右跳跃距离，求从下标 0 到末尾的最少跳跃次数。

    **思路**：把一次跳跃能到达的连续区间视为一层 BFS。扫描当前层时维护下一层最远端；到达当前层边界才增加步数并切换边界。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int jump(vector<int>& nums) {
        int steps = 0;
        int current_end = 0;
        int farthest = 0;
        for (int i = 0; i + 1 < static_cast<int>(nums.size()); ++i) {
          farthest = max(farthest, i + nums[i]);
          if (i == current_end) {
            ++steps;
            current_end = farthest;
          }
        }
        return steps;
      }
    };
    ```
