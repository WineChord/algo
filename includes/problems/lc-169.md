??? problem "LeetCode 169 · 多数元素"
    [打开原题 ↗](https://leetcode.cn/problems/majority-element/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：数组保证存在出现次数严格大于 $\lfloor n/2\rfloor$ 的元素，返回它。

    **思路**：把候选与不同元素成对抵消；真正多数元素删除任意异值对后仍是剩余序列的多数，因此最终候选唯一。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int majorityElement(vector<int>& nums) {
        int candidate = 0;
        int votes = 0;
        for (int value : nums) {
          if (votes == 0) {
            candidate = value;
          }
          votes += value == candidate ? 1 : -1;
        }
        return candidate;
      }
    };
    ```
