??? problem "LeetCode 42 · 接雨水"
    [打开原题 ↗](https://leetcode.cn/problems/trapping-rain-water/){ .problem-source }

    **题意**：柱宽均为 1，给定非负柱高，求雨后能存下的总水量。

    **思路**：维护两端扫描到的最高挡板。较低一侧的当前位置水位已经确定，可以立即结算并向内移动；另一侧至少存在不低于它的挡板。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int trap(vector<int>& height) {
        int l = 0, r = (int)height.size() - 1;
        int leftMax = 0, rightMax = 0;
        long long answer = 0;
        while (l <= r) {
          leftMax = max(leftMax, height[l]);
          rightMax = max(rightMax, height[r]);
          if (leftMax <= rightMax) {
            answer += leftMax - height[l];
            ++l;
          } else {
            answer += rightMax - height[r];
            --r;
          }
        }
        return (int)answer;
      }
    };
    ```
