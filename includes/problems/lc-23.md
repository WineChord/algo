??? problem "LeetCode 23 · 合并 K 个升序链表"
    [打开原题 ↗](https://leetcode.cn/problems/merge-k-sorted-lists/){ .problem-source }

    **题意**：把 `k` 条升序链表合并为一条升序链表。

    **思路**：最小堆维护每条链表当前尚未取出的最小节点；弹出堆顶接到答案后，把它的后继加入堆。

    **复杂度**：设总节点数为 $N$，时间 $O(N\log k)$，额外空间 $O(k)$。

    **C++ 实现**

    <!-- compile:skip -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
        struct Cmp {
            bool operator()(ListNode* a, ListNode* b) const {
                return a->val > b->val;
            }
        };
    public:
        ListNode* mergeKLists(vector<ListNode*>& lists) {
            priority_queue<ListNode*, vector<ListNode*>, Cmp> q;
            for (auto p : lists) if (p) q.push(p);
            ListNode dummy, *tail = &dummy;
            while (!q.empty()) {
                auto p = q.top();
                q.pop();
                tail = tail->next = p;
                if (p->next) q.push(p->next);
            }
            return dummy.next;
        }
    };
    ```
