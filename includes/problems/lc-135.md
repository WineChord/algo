??? problem "LeetCode 135 · 分发糖果"
    [打开原题 ↗](https://leetcode.cn/problems/candy/){ .problem-source }

    **难度与分值**：LeetCode 官方「困难」。

    **题意**：每个孩子至少一颗糖，评分更高者必须比相邻评分更低者多，求最少总数。

    **思路**：左扫满足左邻约束，右扫满足右邻约束；每点取两种单侧最小需求的最大值，恰为全局逐点下界。

    **复杂度**：时间 $O(n)$，额外空间 $O(n)$；斜坡计数可压到 $O(1)$ 空间。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int candy(vector<int>& ratings) {
        int n = ratings.size();
        vector<int> candies(n, 1);
        for (int i = 1; i < n; ++i) {
          if (ratings[i] > ratings[i - 1]) {
            candies[i] = candies[i - 1] + 1;
          }
        }
        int answer = candies[n - 1];
        int fromRight = 1;
        for (int i = n - 2; i >= 0; --i) {
          fromRight = ratings[i] > ratings[i + 1] ? fromRight + 1 : 1;
          answer += max(candies[i], fromRight);
        }
        return answer;
      }
    };
    ```
