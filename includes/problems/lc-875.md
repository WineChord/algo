??? problem "LeetCode 875 · 爱吃香蕉的珂珂"
    [打开原题 ↗](https://leetcode.cn/problems/koko-eating-bananas/){ .problem-source }

    **题意**：每小时从一堆香蕉中吃固定数量，求在 `h` 小时内吃完所有堆所需的最小速度。

    **思路**：速度越大，耗时越短，“能够按时吃完”具有单调性；在 $[1,\max piles]$ 上二分第一个可行速度。

    **复杂度**：时间 $O(n\log M)$，其中 $M=\max piles$；额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int minEatingSpeed(vector<int>& a, int h) {
            int l = 1, r = *max_element(a.begin(), a.end());
            auto ok = [&](int k) {
                long long hours = 0;
                for (int x : a) hours += (x + k - 1LL) / k;
                return hours <= h;
            };
            while (l < r) {
                int m = l + (r - l) / 2;
                if (ok(m)) r = m;
                else l = m + 1;
            }
            return l;
        }
    };
    ```
