??? problem "LeetCode 128 · 最长连续序列"
    [打开原题 ↗](https://leetcode.cn/problems/longest-consecutive-sequence/){ .problem-source }

    **题意**：在未排序整数数组中，求数值连续的最长序列长度；元素不要求在原数组中相邻。

    **思路**：用哈希集合去重。只有前驱 `x - 1` 不存在时才从 `x` 向右扩张，因此每个不同值只会进入一条序列的一次扩张。

    **复杂度**：平均时间 $O(n)$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int longestConsecutive(vector<int>& nums) {
        unordered_set<long long> values(nums.begin(), nums.end());
        int answer = 0;
        for (long long x : values) {
          if (values.contains(x - 1)) continue;
          long long y = x;
          while (values.contains(y)) ++y;
          answer = max(answer, (int)(y - x));
        }
        return answer;
      }
    };
    ```
