??? problem "LeetCode 1044 · 最长重复子串"
    [打开原题 ↗](https://leetcode.cn/problems/longest-duplicate-substring/){ .problem-source }

    **题意**：求字符串中出现至少两次的最长连续子串，两次出现允许重叠。

    **思路**：答案长度具有单调性：若存在长度 $L$ 的重复子串，则更短长度也存在。二分长度，并用双模滚动哈希在 $O(n)$ 内检测同长度窗口是否重复；两个模数显著降低碰撞概率。

    **复杂度**：期望时间 $O(n\log n)$，空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        string longestDupSubstring(string s) {
            int n=s.size();
            if(n<2) return "";
            const long long b=911382323,m1=1000000007,m2=1000000009;
            vector<long long> p1(n+1,1),p2(n+1,1),h1(n+1),h2(n+1);
            for(int i=0;i<n;i++) p1[i+1]=p1[i]*b%m1,p2[i+1]=p2[i]*b%m2,h1[i+1]=(h1[i]*b+s[i])%m1,h2[i+1]=(h2[i]*b+s[i])%m2;
            auto check=[&](int len){
                unordered_map<uint64_t,int> seen;
                for(int i=0;i+len<=n;i++){
                    uint64_t x=(h1[i+len]-h1[i]*p1[len]%m1+m1)%m1,y=(h2[i+len]-h2[i]*p2[len]%m2+m2)%m2,key=x<<32|y;
                    if(auto it=seen.find(key);it!=seen.end()) return it->second;
                    seen[key]=i;
                }
                return -1;
            };
            int l=1,r=n-1,pos=0,best=0;
            while(l<=r){
                int mid=(l+r)/2,p=check(mid);
                if(p>=0) best=mid,pos=p,l=mid+1;
                else r=mid-1;
            }
            return s.substr(pos,best);
        }
    };
    ```
