??? problem "LeetCode 98 · 验证二叉搜索树"
    [打开原题 ↗](https://leetcode.cn/problems/validate-binary-search-tree/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：判断二叉树是否满足每个左子树值严格小于根、右子树值严格大于根的全局搜索树约束。

    **思路**：合法 BST 的中序序列严格递增；显式栈逐点输出并与前一个值比较。

    **复杂度**：时间 $O(n)$，额外空间 $O(h)$。

    **C++ 实现**

    <!-- compile:leetcode-tree -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      bool isValidBST(TreeNode* root) {
        vector<TreeNode*> stack;
        TreeNode* current = root;
        long long previous = LLONG_MIN;
        while (current || !stack.empty()) {
          while (current) {
            stack.push_back(current);
            current = current->left;
          }
          current = stack.back();
          stack.pop_back();
          if (current->val <= previous)
            return false;
          previous = current->val;
          current = current->right;
        }
        return true;
      }
    };
    ```
