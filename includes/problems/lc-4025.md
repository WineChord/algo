??? problem "LeetCode 4025：交通灯的最大等待时间"
    [打开原题 ↗](https://leetcode.cn/problems/minimize-the-maximum-waiting-time-at-synchronized-traffic-lights/){ .problem-source }

    **难度与分值**：中等；第 515 场周赛 Q2 官方分值 4；ZeroTracer 社区估算竞赛分未知（2026-08-19）

    **题意**：同步交通灯拥有相同周期但不同绿灯时长。每辆车可任选一盏灯，求所有车辆等待时间最大值的最小可能值。

    **思路**：灯没有容量限制，车辆之间互不影响。只需保留最长绿灯时长 $G$；到达余数小于 $G$ 时可零等待，否则任意灯都要等到下一周期。

    **复杂度**：时间 $O(C+A)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int minPenalty(int period, vector<int>& lights, vector<int>& arrivalTime) {
        int longestGreen = *max_element(lights.begin(), lights.end());
        int answer = 0;
        for (int arrival : arrivalTime) {
          int remainder = arrival % period;
          if (remainder >= longestGreen) answer = max(answer, period - remainder);
        }
        return answer;
      }
    };
    ```
