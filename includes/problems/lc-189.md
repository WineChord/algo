??? problem "LeetCode 189 · 轮转数组"
    [打开原题 ↗](https://leetcode.cn/problems/rotate-array/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：把数组原地向右轮转 $k$ 个位置。

    **思路**：先整体翻转，再分别翻转新的前 $k$ 段和后 $n-k$ 段，把循环置换转化为三次区间翻转。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      void rotate(vector<int>& nums, int k) {
        int n = nums.size();
        k %= n;
        reverse(nums.begin(), nums.end());
        reverse(nums.begin(), nums.begin() + k);
        reverse(nums.begin() + k, nums.end());
      }
    };
    ```
