??? problem "LeetCode 221 · 最大正方形"
    [打开原题 ↗](https://leetcode.cn/problems/maximal-square/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：在 0/1 矩阵中求全为 1 的最大轴对齐正方形面积。

    **思路**：以当前格为右下角的最大边长由左、上、左上三个状态的最小值加一决定；滚动数组再保存旧左上值。

    **复杂度**：时间 $O(mn)$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int maximalSquare(vector<vector<char>>& matrix) {
        int rows = matrix.size();
        int columns = matrix[0].size();
        vector<int> dp(columns + 1);
        int best = 0;
        for (int row = 1; row <= rows; ++row) {
          int diagonal = 0;
          for (int column = 1; column <= columns; ++column) {
            int up = dp[column];
            if (matrix[row - 1][column - 1] == '1') {
              dp[column] = 1 + min({up, dp[column - 1], diagonal});
              best = max(best, dp[column]);
            } else {
              dp[column] = 0;
            }
            diagonal = up;
          }
        }
        return best * best;
      }
    };
    ```
