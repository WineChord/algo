??? problem "LeetCode 2235 · 两整数相加"
    [打开原题 ↗](https://leetcode.cn/problems/add-two-integers/){ .problem-source }

    **难度**：LeetCode 官方「简单」。

    **题意**：返回两个整数 `num1` 与 `num2` 的和。

    **思路**：题目允许直接使用整数加法；约束保证结果位于 32 位有符号整数范围内，无需额外算法或宽类型。

    **复杂度**：时间 $O(1)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int sum(int num1, int num2) {
        return num1 + num2;
      }
    };
    ```
