??? problem "LeetCode 3016 · 输入单词需要的最少按键次数 II"
    [打开原题 ↗](https://leetcode.cn/problems/minimum-number-of-pushes-to-type-word-ii/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」，2026-07-31 力扣中国每日一题。

    **题意**：重新映射八个电话按键上的字母，求输入给定小写单词的最少按键次数。

    **思路**：八个按键依次提供 8 个成本为 1、2、3 的槽位，最后还有两个成本为 4 的槽位。按字母频率降序、槽位成本升序配对，由交换论证得到最优。

    **复杂度**：时间 $O(|word|+26\log26)$，额外空间 $O(26)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int minimumPushes(string word) {
        array<int, 26> frequency{};
        for (char character : word) {
          ++frequency[character - 'a'];
        }
        sort(frequency.begin(), frequency.end(), greater<int>());
        int answer = 0;
        for (int index = 0; index < 26; ++index) {
          answer += frequency[index] * (index / 8 + 1);
        }
        return answer;
      }
    };
    ```
