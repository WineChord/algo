??? problem "LeetCode 198 · 打家劫舍"
    [打开原题 ↗](https://leetcode.cn/problems/house-robber/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：一排房屋中相邻两间不能同时选择，求可取得的最大金额。

    **思路**：当前位置要么不选并继承前一项最优值，要么选择并接到前两项最优值；滚动维护这两个状态。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int rob(vector<int>& nums) {
        int twoBack = 0;
        int oneBack = 0;
        for (int money : nums) {
          int current = max(oneBack, twoBack + money);
          twoBack = oneBack;
          oneBack = current;
        }
        return oneBack;
      }
    };
    ```
