??? problem "LeetCode 198 · 打家劫舍"
    [打开原题 ↗](https://leetcode.cn/problems/house-robber/){ .problem-source }

    **题意**：一排房屋中相邻两间不能同时偷，求能够取得的最大金额。

    **思路**：处理当前房屋时，要么不偷并继承前一状态，要么偷它并加上前两间之前的最优值。转移为 $f_i=\max(f_{i-1},f_{i-2}+a_i)$，滚动保存两个状态。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int rob(vector<int>& nums) {
            int a=0,b=0;
            for(int x:nums){int c=max(b,a+x);a=b;b=c;}
            return b;
        }
    };
    ```
