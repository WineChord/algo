??? problem "LeetCode 3718：缺失的最小倍数"
    [打开原题 ↗](https://leetcode.cn/problems/smallest-missing-multiple-of-k/){ .problem-source }

    **难度与竞赛分**：简单；第 472 场周赛 Q1 官方分值 3；ZeroTracer 社区估算竞赛分 1227.634（2026-08-25）

    **题意**：给定正整数数组和正整数 $k$，返回没有出现在数组中的最小正整数 $k$ 倍数。

    **思路**：把数组中能被 $k$ 整除的值映射为商并标记。长度为 $n$ 的数组至多占据 $n$ 个商，因此 $1$ 到 $n+1$ 中至少有一个缺失；返回最小未标记商乘 $k$。

    **复杂度**：时间 $O(n)$，额外空间 $O(n)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int missingMultiple(vector<int>& nums, int k) {
        int n = nums.size();
        vector<char> seen(n + 2, false);
        for (int value : nums) {
          if (value % k != 0)
            continue;
          int quotient = value / k;
          if (quotient <= n + 1)
            seen[quotient] = true;
        }
        for (int quotient = 1; quotient <= n + 1; ++quotient) {
          if (!seen[quotient])
            return quotient * k;
        }
        return -1;
      }
    };
    ```
