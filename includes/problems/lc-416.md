??? problem "LeetCode 416 · 分割等和子集"
    [打开原题 ↗](https://leetcode.cn/problems/partition-equal-subset-sum/){ .problem-source }

    **题意**：判断能否把正整数数组分成两个元素和相等的子集。

    **思路**：若总和为奇数则无解；否则问题等价于从每个数至多选一次，能否凑出总和的一半。用一维 0/1 背包，容量必须倒序枚举，避免同一元素被重复使用。

    **复杂度**：设目标和为 $S$，时间 $O(nS)$，空间 $O(S)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        bool canPartition(vector<int>& nums) {
            int s=accumulate(nums.begin(),nums.end(),0);
            if(s&1) return false;
            s/=2;
            vector<char> dp(s+1);
            dp[0]=1;
            for(int x:nums) for(int j=s;j>=x;j--) dp[j]|=dp[j-x];
            return dp[s];
        }
    };
    ```
