??? problem "LeetCode 416 · 分割等和子集"
    [打开原题 ↗](https://leetcode.cn/problems/partition-equal-subset-sum/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：判断能否把正整数数组的全部元素分成两个元素和相等的子集。

    **思路**：总和为奇数时直接无解；否则转化为能否从每个元素至多选一次，凑出总和的一半。容量倒序更新的一维布尔数组保留 0-1 背包语义。

    **复杂度**：设目标和为 $S$，时间 $O(nS)$，额外空间 $O(S)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      bool canPartition(vector<int>& nums) {
        int sum = accumulate(nums.begin(), nums.end(), 0);
        if (sum % 2 == 1) {
          return false;
        }
        int target = sum / 2;
        vector<char> reachable(target + 1);
        reachable[0] = true;
        for (int value : nums) {
          for (int current = target; current >= value; --current) {
            reachable[current] |= reachable[current - value];
          }
          if (reachable[target]) {
            return true;
          }
        }
        return false;
      }
    };
    ```
