??? problem "LeetCode 283 · 移动零"
    [打开原题 ↗](https://leetcode.cn/problems/move-zeroes/){ .problem-source }

    **难度**：LeetCode 官方「简单」。

    **题意**：原地把数组中的所有零移到末尾，同时保持非零元素的相对顺序。

    **思路**：`write` 指向下一个非零元素应写入的位置。扫描到非零值时写到 `write` 并递增；扫描完成后把剩余后缀填零。每个非零值只被写一次，稳定性由扫描顺序保证。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      void moveZeroes(vector<int>& nums) {
        int write = 0;
        for (int x : nums) {
          if (x != 0) nums[write++] = x;
        }
        while (write < (int)nums.size()) nums[write++] = 0;
      }
    };
    ```
