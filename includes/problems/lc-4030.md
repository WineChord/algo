??? problem "LeetCode 4030：判断 ASCII 值回文"
    [打开原题 ↗](https://leetcode.cn/problems/check-ascii-palindromic/){ .problem-source }

    **难度与竞赛分**：简单；第 516 场周赛 Q1 官方分值 3；ZeroTracer 暂无社区估算竞赛分（2026-08-26）

    **题意**：把小写字符串中每个字符的 ASCII 值写成恰好 8 位二进制并依次拼接，判断所得比特串是否为回文。

    **思路**：把每个字符看成一个 8 位块。整串回文当且仅当第 $i$ 个字节等于倒数第 $i$ 个字节按位反转后的值；逐对检查即可，无需构造 $8n$ 位字符串。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
      unsigned char reverseByte(unsigned char value) {
        unsigned char result = 0;
        for (int bit = 0; bit < 8; ++bit) {
          result = static_cast<unsigned char>((result << 1) | (value & 1));
          value >>= 1;
        }
        return result;
      }
    public:
      bool isPalindromic(string s) {
        int n = s.size();
        for (int i = 0; i <= n - 1 - i; ++i) {
          unsigned char left = static_cast<unsigned char>(s[i]);
          unsigned char right = static_cast<unsigned char>(s[n - 1 - i]);
          if (left != reverseByte(right))
            return false;
        }
        return true;
      }
    };
    ```
