??? problem "LeetCode 53 · 最大子数组和"
    [打开原题 ↗](https://leetcode.cn/problems/maximum-subarray/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：求非空连续子数组的最大元素和。

    **思路**：维护必须在当前位置结尾的最优值 $ending_i=\max(a_i,ending_{i-1}+a_i)$，并取所有结尾状态的最大值。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int maxSubArray(vector<int>& nums) {
        int ending = nums[0];
        int answer = nums[0];
        for (int i = 1; i < static_cast<int>(nums.size()); ++i) {
          ending = max(nums[i], ending + nums[i]);
          answer = max(answer, ending);
        }
        return answer;
      }
    };
    ```
