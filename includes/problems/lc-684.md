??? problem "LeetCode 684 · 冗余连接"
    [打开原题 ↗](https://leetcode.cn/problems/redundant-connection/){ .problem-source }

    **题意**：一棵无向树额外加入一条边，返回一条删除后能恢复为树的边。

    **思路**：按输入顺序用并查集合并端点；若一条边的两端已经连通，它就是当前形成环的冗余边。

    **复杂度**：时间 $O(n\alpha(n))$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
        vector<int> p, sz;
        int find(int x) {
            return p[x] == x ? x : p[x] = find(p[x]);
        }
    public:
        vector<int> findRedundantConnection(vector<vector<int>>& edges) {
            int n = edges.size();
            p.resize(n + 1);
            sz.assign(n + 1, 1);
            iota(p.begin(), p.end(), 0);
            for (auto& e : edges) {
                int a = find(e[0]), b = find(e[1]);
                if (a == b) return e;
                if (sz[a] < sz[b]) swap(a, b);
                p[b] = a;
                sz[a] += sz[b];
            }
            return {};
        }
    };
    ```
