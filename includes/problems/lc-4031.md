??? problem "LeetCode 4031：找到所有数组中消失的数字 II"
    [打开原题 ↗](https://leetcode.cn/problems/find-all-numbers-disappeared-in-an-array-ii/){ .problem-source }

    **难度与竞赛分**：中等；第 516 场周赛 Q2 官方分值 4；ZeroTracer 暂无社区估算竞赛分（2026-08-27）

    **题意**：给定数组与闭区间 $[lower,upper]$，把区间内未在数组中出现的整数合并成按值递增的极大连续区间。

    **思路**：值域宽度至多 $10^5$，用存在表标记区间内出现的值，再从左到右输出每个极大连续零段。存在表下标与实际值单调对应，因此无需排序。

    **复杂度**：令 $R=upper-lower+1$，时间 $O(n+R)$，额外空间 $O(R)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      vector<vector<int>> findDisappearedNumbers(vector<int>& nums, int lower, int upper) {
        int range = upper - lower + 1;
        vector<char> present(range, false);
        for (int x : nums) {
          if (lower <= x && x <= upper)
            present[x - lower] = true;
        }
        vector<vector<int>> answer;
        int i = 0;
        while (i < range) {
          if (present[i]) {
            ++i;
            continue;
          }
          int start = i;
          while (i < range && !present[i])
            ++i;
          answer.push_back({lower + start, lower + i - 1});
        }
        return answer;
      }
    };
    ```
