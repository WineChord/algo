??? problem "LeetCode 322 · 零钱兑换"
    [打开原题 ↗](https://leetcode.cn/problems/coin-change/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：每种面额可无限使用，求凑出目标金额所需的最少硬币数；无解返回 $-1$。

    **思路**：令 `dp[x]` 为凑出金额 $x$ 的最少硬币数，枚举最后一枚硬币，从更小金额转移。

    **复杂度**：设硬币数为 $k$，时间 $O(k\cdot amount)$，空间 $O(amount)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int coinChange(vector<int>& coins, int amount) {
        vector<int> dp(amount + 1, amount + 1);
        dp[0] = 0;
        for (int value = 1; value <= amount; ++value) {
          for (int coin : coins) {
            if (coin <= value) {
              dp[value] = min(dp[value], dp[value - coin] + 1);
            }
          }
        }
        return dp[amount] > amount ? -1 : dp[amount];
      }
    };
    ```
