??? problem "LeetCode 2904：最短且字典序最小的美丽子字符串"
    [打开原题 ↗](https://leetcode.cn/problems/shortest-and-lexicographically-smallest-beautiful-string/){ .problem-source }

    **难度与竞赛分**：中等；第 367 场周赛 Q2 官方分值 4；ZeroTracer 社区估算竞赛分 1483.304（2026-08-26）

    **题意**：在二进制串中选出恰含 $k$ 个 `1` 的子字符串，先最小化长度，再在最短候选中取字典序最小者。

    **思路**：最短候选必以 `1` 开始和结束，所以只需记录所有 `1` 的位置，并枚举每组连续的 $k$ 个 `1` 所确定的紧致区间；按长度、字典序依次比较。

    **复杂度**：位置窗口扫描 $O(n)$；计入候选字符串构造与比较后最坏时间 $O(n^2)$，额外空间 $O(n)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      string shortestBeautifulSubstring(string s, int k) {
        vector<int> positions;
        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
          if (s[i] == '1')
            positions.push_back(i);
        }
        if (static_cast<int>(positions.size()) < k)
          return "";
        string answer;
        for (int i = 0; i + k <= static_cast<int>(positions.size()); ++i) {
          string current = s.substr(positions[i], positions[i + k - 1] - positions[i] + 1);
          if (answer.empty() || current.size() < answer.size() ||
              (current.size() == answer.size() && current < answer)) {
            answer = current;
          }
        }
        return answer;
      }
    };
    ```
