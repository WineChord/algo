??? problem "LeetCode 48 · 旋转图像"
    [打开原题 ↗](https://leetcode.cn/problems/rotate-image/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：把方阵原地顺时针旋转 $90^\circ$。

    **思路**：顺时针坐标变换可分解为主对角线转置与逐行翻转；两步都只交换对称位置，不需要额外矩阵。

    **复杂度**：时间 $O(n^2)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      void rotate(vector<vector<int>>& matrix) {
        int n = matrix.size();
        for (int i = 0; i < n; ++i) {
          for (int j = i + 1; j < n; ++j) {
            swap(matrix[i][j], matrix[j][i]);
          }
        }
        for (vector<int>& row : matrix) {
          reverse(row.begin(), row.end());
        }
      }
    };
    ```
