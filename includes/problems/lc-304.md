??? problem "LeetCode 304 · 二维区域和检索"
    [打开原题 ↗](https://leetcode.cn/problems/range-sum-query-2d-immutable/){ .problem-source }

    **题意**：对静态矩阵进行多次矩形区域和查询。

    **思路**：预处理带一圈哨兵的二维前缀和；每次查询用容斥组合四个前缀矩形。

    **复杂度**：预处理 $O(mn)$，单次查询 $O(1)$，额外空间 $O(mn)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class NumMatrix {
        vector<vector<int>> s;
    public:
        NumMatrix(vector<vector<int>>& a) {
            int m = a.size(), n = a[0].size();
            s.assign(m + 1, vector<int>(n + 1));
            for (int i = 1; i <= m; ++i)
                for (int j = 1; j <= n; ++j)
                    s[i][j] = a[i - 1][j - 1] + s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1];
        }
        int sumRegion(int r1, int c1, int r2, int c2) {
            return s[r2 + 1][c2 + 1] - s[r1][c2 + 1] - s[r2 + 1][c1] + s[r1][c1];
        }
    };
    ```
