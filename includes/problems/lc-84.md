??? problem "LeetCode 84 · 柱状图中最大的矩形"
    [打开原题 ↗](https://leetcode.cn/problems/largest-rectangle-in-histogram/){ .problem-source }

    **题意**：给定每根柱子的高度，求柱状图中完全由相邻柱子覆盖的最大矩形面积。

    **思路**：维护高度单调递增的下标栈。新高度更小时，弹出的柱子以当前下标为右侧第一个更矮位置，弹栈后的栈顶给出左边界。

    **复杂度**：时间 $O(n)$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int largestRectangleArea(vector<int>& h) {
            stack<int> st;
            int ans = 0, n = h.size();
            for (int i = 0; i <= n; ++i) {
                int cur = i == n ? 0 : h[i];
                while (!st.empty() && h[st.top()] > cur) {
                    int x = h[st.top()];
                    st.pop();
                    int l = st.empty() ? -1 : st.top();
                    ans = max(ans, x * (i - l - 1));
                }
                st.push(i);
            }
            return ans;
        }
    };
    ```
