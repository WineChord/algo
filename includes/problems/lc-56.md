??? problem "LeetCode 56 · 合并区间"
    [打开原题 ↗](https://leetcode.cn/problems/merge-intervals/){ .problem-source }

    **难度**：LeetCode 官方「中等」。

    **题意**：合并所有互相重叠的闭区间，返回互不重叠且覆盖范围相同的区间集合。

    **思路**：按左端点排序。顺序扫描时，若新区间与答案末尾相交就扩展右端点；否则排序保证末尾块以后不会再被扩展，可以开启新区间。

    **复杂度**：时间 $O(n\log n)$，除排序外额外空间 $O(n)$ 用于答案。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      vector<vector<int>> merge(vector<vector<int>>& intervals) {
        sort(intervals.begin(), intervals.end());
        vector<vector<int>> answer;
        for (const auto& segment : intervals) {
          if (answer.empty() || segment[0] > answer.back()[1]) {
            answer.push_back(segment);
          } else {
            answer.back()[1] = max(answer.back()[1], segment[1]);
          }
        }
        return answer;
      }
    };
    ```
