??? problem "LeetCode 206 · 反转链表"
    [打开原题 ↗](https://leetcode.cn/problems/reverse-linked-list/){ .problem-source }

    **难度**：LeetCode 官方「简单」。

    **题意**：反转一条单链表并返回新的头节点。

    **思路**：维护已经反转的前缀 `prev` 与尚未处理的后缀头 `current`。改写当前节点的边之前先保存 `next`，然后整体推进三个指针。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode-list -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      ListNode* reverseList(ListNode* head) {
        ListNode* prev = nullptr;
        ListNode* current = head;
        while (current) {
          ListNode* next = current->next;
          current->next = prev;
          prev = current;
          current = next;
        }
        return prev;
      }
    };
    ```
