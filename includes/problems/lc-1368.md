??? problem "LeetCode 1368 · 使网格图至少有一条有效路径的最小代价"
    [打开原题 ↗](https://leetcode.cn/problems/minimum-cost-to-make-at-least-one-valid-path-in-a-grid/){ .problem-source }

    **题意**：每个网格指向一个相邻方向，可以花费 $1$ 修改某格方向；求从左上角走到右下角的最小修改次数。

    **思路**：从一个格子走向它原本指示的方向代价为 $0$，走向其余方向代价为 $1$，因此网格变成边权只有 $0/1$ 的图。用双端队列做 0-1 BFS：零权更新放队首，一权更新放队尾。

    **复杂度**：时间 $O(mn)$，空间 $O(mn)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int minCost(vector<vector<int>>& grid) {
            int m=grid.size(),n=grid[0].size(),dir[5][2]={{0,0},{0,1},{0,-1},{1,0},{-1,0}};
            vector d(m,vector<int>(n,INT_MAX));
            vector vis(m,vector<char>(n));
            deque<pair<int,int>> q;
            d[0][0]=0;
            q.push_front({0,0});
            while(!q.empty()){
                auto [x,y]=q.front();
                q.pop_front();
                if(vis[x][y]) continue;
                vis[x][y]=1;
                for(int k=1;k<=4;k++){
                    int nx=x+dir[k][0],ny=y+dir[k][1],w=grid[x][y]!=k;
                    if(nx<0||nx>=m||ny<0||ny>=n||d[nx][ny]<=d[x][y]+w) continue;
                    d[nx][ny]=d[x][y]+w;
                    if(w) q.push_back({nx,ny});
                    else q.push_front({nx,ny});
                }
            }
            return d[m-1][n-1];
        }
    };
    ```
