??? problem "LeetCode 509 · 斐波那契数"
    [打开原题 ↗](https://leetcode.cn/problems/fibonacci-number/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：计算 F(0)=0、F(1)=1、F(n)=F(n-1)+F(n-2) 定义的第 n 个斐波那契数。

    **思路**：自底向上递推时，下一项只依赖前两项；用两个变量维护滚动不变量，避免递归树的重复计算和线性数组。

    **复杂度**：时间 O(n)，空间 O(1)。

    **C++ 实现**

    <!-- compile:standalone -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int fib(int n) {
        int previous = 0;
        int current = 1;
        for (int i = 0; i < n; ++i) {
          int next = previous + current;
          previous = current;
          current = next;
        }
        return previous;
      }
    };
    int main() {
      cout << Solution().fib(4) << '\n';
    }
    ```
