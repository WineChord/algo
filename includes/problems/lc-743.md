??? problem "LeetCode 743 · 网络延迟时间"
    [打开原题 ↗](https://leetcode.cn/problems/network-delay-time/){ .problem-source }

    **题意**：信号从节点 $k$ 出发，沿带正权的有向边传播，求所有节点收到信号的最短时间；若有节点不可达则返回 $-1$。

    **思路**：从 $k$ 运行 Dijkstra，优先扩展当前距离最小的节点，并跳过优先队列中的过期状态。最远节点的最短路就是全部收到信号的时刻。

    **复杂度**：时间 $O((n+m)\log n)$，空间 $O(n+m)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int networkDelayTime(vector<vector<int>>& times,int n,int k) {
            vector<vector<pair<int,int>>> g(n+1);
            for(auto& e:times) g[e[0]].push_back({e[1],e[2]});
            vector<int> d(n+1,INT_MAX);
            priority_queue<pair<int,int>,vector<pair<int,int>>,greater<>> q;
            d[k]=0;
            q.push({0,k});
            while(!q.empty()){
                auto [du,u]=q.top();
                q.pop();
                if(du!=d[u]) continue;
                for(auto [v,w]:g[u]) if(d[v]>du+w) d[v]=du+w,q.push({d[v],v});
            }
            int ans=*max_element(d.begin()+1,d.end());
            return ans==INT_MAX?-1:ans;
        }
    };
    ```
