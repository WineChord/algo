??? problem "LeetCode 207 · 课程表"
    [打开原题 ↗](https://leetcode.cn/problems/course-schedule/){ .problem-source }

    **题意**：课程之间存在先修关系，判断能否完成所有课程。

    **思路**：先修关系形成有向图。用 Kahn 拓扑排序把所有入度为零的节点入队，每删除一个节点就降低后继入度；若最终删除了全部节点则无环，否则剩余部分含环。

    **复杂度**：时间 $O(n+m)$，空间 $O(n+m)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        bool canFinish(int n,vector<vector<int>>& prerequisites) {
            vector<vector<int>> g(n);
            vector<int> in(n);
            for(auto& e:prerequisites) g[e[1]].push_back(e[0]),in[e[0]]++;
            queue<int> q;
            for(int i=0;i<n;i++) if(!in[i]) q.push(i);
            int cnt=0;
            while(!q.empty()){
                int u=q.front();
                q.pop();
                cnt++;
                for(int v:g[u]) if(!--in[v]) q.push(v);
            }
            return cnt==n;
        }
    };
    ```
