??? problem "第 511 场周赛 Q2 · LeetCode 3997 · 统计二叉树中支配节点的数量"
    [打开原题 ↗](https://leetcode.cn/problems/count-dominant-nodes-in-a-binary-tree/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」、周赛官方 4 分；[ZeroTracer](https://zerotrac.github.io/leetcode_problem_rating/) 社区估算竞赛分 1426.6（检索于 2026-07-27）。

    **题意**：完整二叉树中，若节点值等于其整棵子树的最大值，则该节点为支配节点；统计支配节点数。

    **思路**：后序遍历为父节点返回子树最大值和支配节点数。左右摘要与当前值合并后，当前节点是否支配即可在常数时间判断。

    **复杂度**：时间 $O(n)$；由完整二叉树高度保证，递归栈空间 $O(\log n)$。

    **C++ 实现**

    <!-- compile:leetcode-tree -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
      pair<int, int> dfs(TreeNode* node) {
        if (!node) return {INT_MIN, 0};
        auto [leftMax, leftCount] = dfs(node->left);
        auto [rightMax, rightCount] = dfs(node->right);
        int subtreeMax = max({node->val, leftMax, rightMax});
        int count = leftCount + rightCount + (node->val == subtreeMax);
        return {subtreeMax, count};
      }
    public:
      int countDominantNodes(TreeNode* root) {
        return dfs(root).second;
      }
    };
    ```
