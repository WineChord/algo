??? problem "LeetCode 862 · 和至少为 K 的最短子数组"
    [打开原题 ↗](https://leetcode.cn/problems/shortest-subarray-with-sum-at-least-k/){ .problem-source }

    **题意**：数组允许负数，求元素和至少为 `k` 的最短非空连续子数组长度。

    **思路**：转成前缀和差。维护前缀和单调递增的下标队列；当前前缀能满足队首时更新答案，队尾前缀不小于当前值时将其淘汰。

    **复杂度**：时间 $O(n)$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int shortestSubarray(vector<int>& a, int k) {
            int n = a.size(), ans = n + 1;
            vector<long long> s(n + 1);
            for (int i = 0; i < n; ++i) s[i + 1] = s[i] + a[i];
            deque<int> q;
            for (int i = 0; i <= n; ++i) {
                while (!q.empty() && s[i] - s[q.front()] >= k) {
                    ans = min(ans, i - q.front());
                    q.pop_front();
                }
                while (!q.empty() && s[q.back()] >= s[i]) q.pop_back();
                q.push_back(i);
            }
            return ans <= n ? ans : -1;
        }
    };
    ```
