??? problem "LeetCode 50 · Pow(x, n)"
    [打开原题 ↗](https://leetcode.cn/problems/powx-n/){ .problem-source }

    **题意**：实现 \(x^n\)，其中指数 \(n\) 是 32 位有符号整数。

    **思路**：二进制快速幂：指数每次减半，底数同步平方；当前二进制位为 \(1\) 时把底数乘入答案。先把指数转成 `long long` 再取负，避免 `INT_MIN` 溢出。

    **复杂度**：时间 \(O(\log |n|)\)，空间 \(O(1)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        double myPow(double x,int n) {
            long long k=n;
            if(k<0) x=1/x,k=-k;
            double ans=1;
            while(k){
                if(k&1) ans*=x;
                x*=x;
                k>>=1;
            }
            return ans;
        }
    };
    ```
