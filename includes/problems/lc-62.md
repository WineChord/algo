??? problem "LeetCode 62：不同路径"
    [打开原题 ↗](https://leetcode.cn/problems/unique-paths/){ .problem-source }

    **难度**：中等

    **题意**：机器人从 $m\times n$ 网格左上角出发，每步只能向右或向下，求到达右下角的不同路径数。

    **思路**：每条路径含有 $m-1$ 次向下和 $n-1$ 次向右；选择总共 $m+n-2$ 步中哪些位置向下，就与合法路径形成双射，因此答案是 $\binom{m+n-2}{m-1}$。用较小的选择数逐项乘除，避免阶乘与额外空间。

    **复杂度**：时间 $O(\min(m,n))$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int uniquePaths(int m, int n) {
        int total = m + n - 2;
        int choose = min(m - 1, n - 1);
        long long answer = 1;
        for (int i = 1; i <= choose; ++i) {
          answer = answer * (total - choose + i) / i;
        }
        return static_cast<int>(answer);
      }
    };
    ```
