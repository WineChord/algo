??? problem "LeetCode 410 · 分割数组的最大值"
    [打开原题 ↗](https://leetcode.cn/problems/split-array-largest-sum/){ .problem-source }

    **题意**：把非负数组分成 `k` 个非空连续子数组，使各段和的最大值尽可能小。

    **思路**：给定上限 `x`，贪心地尽量延长每一段可得到最少段数；`x` 越大越容易分割，因此二分最小可行上限。

    **复杂度**：时间 $O(n\log S)$，其中 $S$ 为数组和；额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int splitArray(vector<int>& a, int k) {
            long long l = *max_element(a.begin(), a.end());
            long long r = accumulate(a.begin(), a.end(), 0LL);
            auto ok = [&](long long limit) {
                int parts = 1;
                long long sum = 0;
                for (int x : a) {
                    if (sum + x > limit) ++parts, sum = 0;
                    sum += x;
                }
                return parts <= k;
            };
            while (l < r) {
                long long m = l + (r - l) / 2;
                if (ok(m)) r = m;
                else l = m + 1;
            }
            return l;
        }
    };
    ```
