??? problem "LeetCode 421 · 数组中两个数的最大异或值"
    [打开原题 ↗](https://leetcode.cn/problems/maximum-xor-of-two-numbers-in-an-array/){ .problem-source }

    **题意**：从非负整数数组中选两个数，求它们能够取得的最大异或值。

    **思路**：把所有数的二进制位插入 01-Trie。查询一个数时从高位到低位贪心：若存在与当前位相反的分支就优先走它，这一位便能贡献 $1$；高位最优后，低位才有比较意义。

    **复杂度**：时间 $O(31n)$，空间 $O(31n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int findMaximumXOR(vector<int>& nums) {
            vector<array<int,2>> t(1);
            for(int x:nums){
                int u=0;
                for(int k=30;k>=0;k--){
                    int b=x>>k&1;
                    if(!t[u][b]) t[u][b]=t.size(),t.push_back({});
                    u=t[u][b];
                }
            }
            int ans=0;
            for(int x:nums){
                int u=0,cur=0;
                for(int k=30;k>=0;k--){
                    int b=x>>k&1,w=b^1;
                    if(t[u][w]) cur|=1<<k,u=t[u][w];
                    else u=t[u][b];
                }
                ans=max(ans,cur);
            }
            return ans;
        }
    };
    ```
