??? problem "LeetCode 3996 · 偶数次骑士移动"
    [打开原题 ↗](https://leetcode.cn/problems/even-number-of-knight-moves/){ .problem-source }

    **题意**：在标准 $8\times8$ 棋盘上，判断骑士能否用偶数次移动从 `start` 到达 `target`；0 次也算偶数。

    **思路**：骑士每步让坐标和奇偶翻转，而标准棋盘的骑士图连通。同色两点间路径必为偶数，异色两点间路径必为奇数。

    **复杂度**：时间 $O(1)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      bool canReach(vector<int>& start, vector<int>& target) {
        return ((start[0] + start[1]) & 1) == ((target[0] + target[1]) & 1);
      }
    };
    ```
