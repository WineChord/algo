??? problem "LeetCode 27 · 移除元素"
    [打开原题 ↗](https://leetcode.cn/problems/remove-element/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：原地移除数组中所有等于 `val` 的元素，返回有效前缀长度。

    **思路**：写指针维护已经确认保留的区间 `[0,write)`；读到不等于 `val` 的元素时写入并推进边界。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int removeElement(vector<int>& nums, int val) {
        int write = 0;
        for (int value : nums) {
          if (value != val) {
            nums[write++] = value;
          }
        }
        return write;
      }
    };
    ```
