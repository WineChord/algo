??? problem "LeetCode 300 · 最长递增子序列"
    [打开原题 ↗](https://leetcode.cn/problems/longest-increasing-subsequence/){ .problem-source }

    **题意**：求数组中严格递增子序列的最大长度，子序列不要求连续。

    **思路**：维护 `d[len-1]` 为长度为 `len` 的递增子序列可以取得的最小末尾。对每个数用 `lower_bound` 找第一个不小于它的位置并替换；数组长度就是答案。这是“贪心维护最优结尾 + 二分”的经典写法。

    **复杂度**：时间 $O(n\log n)$，空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int lengthOfLIS(vector<int>& nums) {
            vector<int> d;
            for(int x:nums){
                auto it=lower_bound(d.begin(),d.end(),x);
                if(it==d.end()) d.push_back(x);
                else *it=x;
            }
            return d.size();
        }
    };
    ```
