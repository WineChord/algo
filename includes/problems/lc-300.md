??? problem "LeetCode 300 · 最长递增子序列"
    [打开原题 ↗](https://leetcode.cn/problems/longest-increasing-subsequence/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：求整数数组中最长严格递增子序列的长度，所选元素不要求连续。

    **思路**：维护 `tails[len-1]` 为长度为 `len` 的递增子序列可取得的最小末尾。每个数用 `lower_bound` 替换第一个不小于它的末尾；数组长度就是答案。

    **复杂度**：时间 $O(n\log n)$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int lengthOfLIS(vector<int>& nums) {
        vector<int> tails;
        for (int value : nums) {
          auto it = lower_bound(tails.begin(), tails.end(), value);
          if (it == tails.end()) {
            tails.push_back(value);
          } else {
            *it = value;
          }
        }
        return tails.size();
      }
    };
    ```
