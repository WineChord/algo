??? problem "LeetCode 295 · 数据流的中位数"
    [打开原题 ↗](https://leetcode.cn/problems/find-median-from-data-stream/){ .problem-source }

    **难度与分值**：LeetCode 官方「困难」。

    **题意**：实现一个持续加入整数并随时返回当前中位数的数据结构。

    **思路**：大根堆保存较小一半，小根堆保存较大一半；每次插入后同时维护有序分割和大小差不超过一。

    **复杂度**：加入 $O(\log n)$，查询 $O(1)$，空间 $O(n)$。

    **C++ 实现**

    <!-- compile:standalone -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class MedianFinder {
      priority_queue<int> lower;
      priority_queue<int, vector<int>, greater<int>> upper;
    public:
      MedianFinder() = default;
      void addNum(int num) {
        lower.push(num);
        upper.push(lower.top());
        lower.pop();
        if (upper.size() > lower.size()) {
          lower.push(upper.top());
          upper.pop();
        }
      }
      double findMedian() {
        if (lower.size() > upper.size()) {
          return lower.top();
        }
        return (static_cast<long long>(lower.top()) + upper.top()) / 2.0;
      }
    };
    int main() {
    }
    ```
