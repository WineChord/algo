??? problem "LeetCode 295 · 数据流的中位数"
    [打开原题 ↗](https://leetcode.cn/problems/find-median-from-data-stream/){ .problem-source }

    **题意**：支持不断加入整数，并随时返回目前所有整数的中位数。

    **思路**：最大堆保存较小的一半，最小堆保存较大的一半；维持两堆大小差不超过 `1` 且所有左堆元素不大于右堆。

    **复杂度**：插入 \(O(\log n)\)，查询 \(O(1)\)，额外空间 \(O(n)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class MedianFinder {
        priority_queue<int> lo;
        priority_queue<int, vector<int>, greater<int>> hi;
    public:
        MedianFinder() {}
        void addNum(int x) {
            lo.push(x);
            hi.push(lo.top());
            lo.pop();
            if (hi.size() > lo.size()) {
                lo.push(hi.top());
                hi.pop();
            }
        }
        double findMedian() {
            if (lo.size() > hi.size()) return lo.top();
            return (lo.top() + (long long)hi.top()) / 2.0;
        }
    };
    ```
