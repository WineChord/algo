??? problem "LeetCode 1464 · 数组中两元素的最大乘积"
    [打开原题 ↗](https://leetcode.cn/problems/maximum-product-of-two-elements-in-an-array/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」，第 191 场周赛官方分值 $3$；[ZeroTracer](https://zerotrac.github.io/leetcode_problem_rating/) 社区估算竞赛分 $1121.1$（检索于 2026-07-27）。

    **题意**：从正整数数组中选择两个不同位置 $i\ne j$，最大化 $(a_i-1)(a_j-1)$。约束为 $2\le n\le 500$、$1\le a_i\le 1000$。

    **思路**：函数 $x\mapsto x-1$ 在合法值域上非负且严格递增，因此最优答案由数组中按出现位置计数的最大值与次大值组成。扫描时维护这两个极值即可。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int maxProduct(vector<int>& nums) {
        int a = 0, b = 0;
        for (int x : nums) {
          if (x >= a) {
            b = a;
            a = x;
          } else if (x > b) {
            b = x;
          }
        }
        return (a - 1) * (b - 1);
      }
    };
    ```
