??? problem "LeetCode 39 · 组合总和"
    [打开原题 ↗](https://leetcode.cn/problems/combination-sum/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：从互不相同的正整数中可重复取数，返回和为目标值的全部无序组合。

    **思路**：排序后只允许下标单调不降地选择，天然消除排列重复；候选大于剩余目标时立即停止当前层。

    **复杂度**：最坏时间为指数级，递归辅助空间 $O(target/\min(candidates))$，另计输出。

    **C++ 实现**

    <!-- compile:standalone -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
      vector<vector<int>> answers;
      vector<int> path;
      void dfs(const vector<int>& candidates, int start, int remaining) {
        if (remaining == 0) {
          answers.push_back(path);
          return;
        }
        for (int i = start; i < static_cast<int>(candidates.size()); ++i) {
          int value = candidates[i];
          if (value > remaining) {
            break;
          }
          path.push_back(value);
          dfs(candidates, i, remaining - value);
          path.pop_back();
        }
      }
    public:
      vector<vector<int>> combinationSum(vector<int>& candidates, int target) {
        sort(candidates.begin(), candidates.end());
        dfs(candidates, 0, target);
        return answers;
      }
    };
    ```
