??? problem "LeetCode 3471：找出最大的几近缺失整数"
    [打开原题 ↗](https://leetcode.cn/problems/find-the-largest-almost-missing-integer/){ .problem-source }

    **难度与分值**：简单；第 439 场周赛 Q1 官方分值 3；ZeroTracer 社区估算竞赛分 1308.23（2026-08-18）

    **题意**：返回恰好出现在一个长度为 k 的连续子数组中的最大整数；同一窗口内重复出现只计该窗口一次。

    **思路**：k=1 时窗口数等于全局频率，k=n 时只有一个窗口；其余情形只有首尾位置各属于唯一窗口，候选还必须全局只出现一次。

    **复杂度**：时间 O(n)，额外空间 O(V)，固定值域下为 O(1)。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int largestInteger(vector<int>& nums, int k) {
        int n = nums.size();
        if (k == n) return *max_element(nums.begin(), nums.end());
        array<int, 51> frequency{};
        for (int value : nums) ++frequency[value];
        if (k == 1) {
          for (int value = 50; value >= 0; --value) {
            if (frequency[value] == 1) return value;
          }
          return -1;
        }
        int answer = -1;
        if (frequency[nums.front()] == 1) answer = nums.front();
        if (frequency[nums.back()] == 1) answer = max(answer, nums.back());
        return answer;
      }
    };
    ```
