??? problem "LeetCode 31 · 下一个排列"
    [打开原题 ↗](https://leetcode.cn/problems/next-permutation/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：把整数排列原地改成字典序严格更大的最小排列；不存在时改成最小排列。

    **思路**：找最右上升转折点，用右侧最小的更大元素进位，再反转原本非递增的后缀得到最小尾部。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      void nextPermutation(vector<int>& nums) {
        int pivot = static_cast<int>(nums.size()) - 2;
        while (pivot >= 0 && nums[pivot] >= nums[pivot + 1]) {
          --pivot;
        }
        if (pivot >= 0) {
          int successor = nums.size() - 1;
          while (nums[successor] <= nums[pivot]) {
            --successor;
          }
          swap(nums[pivot], nums[successor]);
        }
        reverse(nums.begin() + pivot + 1, nums.end());
      }
    };
    ```
