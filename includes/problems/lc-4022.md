??? problem "LeetCode 4022：无限字符串里第 K 个数字"
    [打开原题 ↗](https://leetcode.cn/problems/k-th-digit-in-infinite-string/){ .problem-source }

    **难度与竞赛分**：中等；第 189 场双周赛 Q3 官方分值 5；ZeroTracer 社区估算竞赛分 1914.972（2026-08-24）

    **题意**：把正整数按每 10 个一块依次拼接，偶数编号块升序、奇数编号块降序；求所得无限数字串的第 $k$ 个数字。

    **思路**：块内重排不改变同一位数段的总字符数，先按位数跳过完整段。余量除以位数得到目标整数的序号，再由十数块奇偶决定该块内是正向还是反向映射，最后取目标数位。

    **复杂度**：时间 $O(\log k)$，额外空间 $O(\log k)$（来自整数转字符串）。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int kthDigit(long long k) {
        if (k <= 9) return static_cast<int>(k);
        k -= 9;
        long long power = 10;
        int digits = 2;
        while (true) {
          __int128 segment = static_cast<__int128>(9) * power * digits;
          if (segment >= k) break;
          k -= static_cast<long long>(segment);
          power *= 10;
          ++digits;
        }
        long long numberIndex = (k - 1) / digits;
        int digitIndex = static_cast<int>((k - 1) % digits);
        long long blockStart = power + numberIndex / 10 * 10;
        long long block = blockStart / 10;
        long long offset = numberIndex % 10;
        long long value = block % 2 == 0 ? blockStart + offset : blockStart + 9 - offset;
        return to_string(value)[digitIndex] - '0';
      }
    };
    ```
