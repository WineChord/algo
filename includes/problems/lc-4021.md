??? problem "LeetCode 4021：得到旋转回文字符串的最少操作次数 I"
    [打开原题 ↗](https://leetcode.cn/problems/minimum-operations-to-make-a-rotated-palindrome-i/){ .problem-source }

    **难度与竞赛分**：中等；第 189 场双周赛 Q2 官方分值 5；ZeroTracer 社区估算竞赛分 1517.775（2026-08-23）

    **题意**：每次可把一个字符沿 `a` 到 `z` 的环递增一步，或把字符串循环左移一位；求变成回文串的最少操作数。

    **思路**：枚举 $0$ 到 $n-1$ 次左移。固定旋转后，各镜像对独立；字符差为 $d$ 时，把两端变成相同字符的最少代价为 $\min(d,26-d)$。把镜像对代价与旋转次数相加后取最小。

    **复杂度**：时间 $O(n^2)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int minOperations(string s) {
        int n = static_cast<int>(s.size());
        int answer = numeric_limits<int>::max();
        for (int rotation = 0; rotation < n; ++rotation) {
          int cost = rotation;
          for (int left = 0; left < n / 2; ++left) {
            int right = n - 1 - left;
            int first = s[(rotation + left) % n] - 'a';
            int second = s[(rotation + right) % n] - 'a';
            int difference = abs(first - second);
            cost += min(difference, 26 - difference);
          }
          answer = min(answer, cost);
        }
        return answer;
      }
    };
    ```
