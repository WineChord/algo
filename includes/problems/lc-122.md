??? problem "LeetCode 122 · 买卖股票的最佳时机 II"
    [打开原题 ↗](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock-ii/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：每天最多持有一股，可完成任意多次交易，求最大利润。

    **思路**：任意上涨区间的端点差都可拆成其中全部正相邻差；把每段上涨逐日兑现既合法又不损失利润。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int maxProfit(vector<int>& prices) {
        int answer = 0;
        for (int i = 1; i < static_cast<int>(prices.size()); ++i) {
          answer += max(0, prices[i] - prices[i - 1]);
        }
        return answer;
      }
    };
    ```
