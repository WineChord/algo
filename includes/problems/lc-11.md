??? problem "LeetCode 11 · 盛最多水的容器"
    [打开原题 ↗](https://leetcode.cn/problems/container-with-most-water/){ .problem-source }

    **难度**：LeetCode 官方「中等」。

    **题意**：从若干竖线中选择两条，使它们与横轴围成的容器面积最大。

    **思路**：双指针从两端开始。若左端不高于右端，任何保留左端而缩小宽度的候选都不可能超过当前面积，因此可以永久删除左端；另一侧对称。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int maxArea(vector<int>& height) {
        int left = 0, right = static_cast<int>(height.size()) - 1;
        int answer = 0;
        while (left < right) {
          answer = max(answer, (right - left) * min(height[left], height[right]));
          if (height[left] <= height[right]) ++left;
          else --right;
        }
        return answer;
      }
    };
    ```
