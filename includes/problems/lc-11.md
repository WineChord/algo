??? problem "LeetCode 11 · 盛最多水的容器"
    [打开原题 ↗](https://leetcode.cn/problems/container-with-most-water/){ .problem-source }

    **题意**：从若干竖线中选择两条，使它们与横轴围成的容器面积最大。

    **思路**：双指针从两端开始。面积由较短边限制，因此每次只移动较短的一端，才可能得到更高的有效高度。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int maxArea(vector<int>& h) {
            int l = 0, r = h.size() - 1;
            long long ans = 0;
            while (l < r) {
                ans = max(ans, 1LL * min(h[l], h[r]) * (r - l));
                if (h[l] < h[r]) ++l;
                else --r;
            }
            return ans;
        }
    };
    ```
