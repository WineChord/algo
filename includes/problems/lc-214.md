??? problem "LeetCode 214 · 最短回文串"
    [打开原题 ↗](https://leetcode.cn/problems/shortest-palindrome/){ .problem-source }

    **题意**：只能在原字符串前面添加字符，求能够得到的最短回文串。

    **思路**：关键是找到原串最长的回文前缀。对 `s + "#" + reverse(s)` 求前缀函数，末值就是该前缀长度；把剩余后缀反转后补到最前面即可。

    **复杂度**：时间 \(O(n)\)，空间 \(O(n)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        string shortestPalindrome(string s) {
            string r=s;
            reverse(r.begin(),r.end());
            string t=s+"#"+r;
            vector<int> pi(t.size());
            for(int i=1,j=0;i<(int)t.size();i++){
                while(j&&t[i]!=t[j]) j=pi[j-1];
                if(t[i]==t[j]) j++;
                pi[i]=j;
            }
            return r.substr(0,s.size()-pi.back())+s;
        }
    };
    ```
