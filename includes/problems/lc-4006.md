??? problem "LeetCode 4006 · 统计有效前缀数目"
    [打开原题 ↗](https://leetcode.cn/problems/count-valid-prefixes/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」，第 188 场双周赛官方 3 分；ZeroTracer 社区估算竞赛分未知（检索于 2026-08-09）。

    **题意**：统计二进制字符串中能够重排为相邻字符不同序列的非空前缀数。

    **思路**：二进制多重集可以交替排列当且仅当零和一的数量差绝对值不超过一；单次扫描维护前缀计数差即可。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:standalone -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int countValidPrefixes(string s) {
        int difference = 0;
        int answer = 0;
        for (char ch : s) {
          difference += ch == '0' ? 1 : -1;
          answer += abs(difference) <= 1;
        }
        return answer;
      }
    };
    int main() {
    }
    ```
