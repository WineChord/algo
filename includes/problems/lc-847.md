??? problem "LeetCode 847 · 访问所有节点的最短路径"
    [打开原题 ↗](https://leetcode.cn/problems/shortest-path-visiting-all-nodes/){ .problem-source }

    **题意**：在无向连通图中可以从任意节点出发、重复经过节点和边，求访问全部节点的最短路径长度。

    **思路**：普通 BFS 状态不足以区分已经访问过哪些点。把状态扩成 `(当前节点, 已访问集合)`，从每个节点的单点集合同时出发做多源 BFS；首次到达全集掩码时即为最短距离。

    **复杂度**：时间 $O((n+m)2^n)$，空间 $O(n2^n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int shortestPathLength(vector<vector<int>>& graph) {
            int n=graph.size(),all=(1<<n)-1;
            vector d(n,vector<int>(1<<n,-1));
            queue<pair<int,int>> q;
            for(int i=0;i<n;i++) d[i][1<<i]=0,q.push({i,1<<i});
            while(!q.empty()){
                auto [u,s]=q.front();
                q.pop();
                if(s==all) return d[u][s];
                for(int v:graph[u]){
                    int ns=s|1<<v;
                    if(d[v][ns]<0) d[v][ns]=d[u][s]+1,q.push({v,ns});
                }
            }
            return 0;
        }
    };
    ```
