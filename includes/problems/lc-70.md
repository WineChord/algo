??? problem "LeetCode 70 · 爬楼梯"
    [打开原题 ↗](https://leetcode.cn/problems/climbing-stairs/){ .problem-source }

    **题意**：每次可以爬 \(1\) 或 \(2\) 级台阶，求到达第 \(n\) 级的方案数。

    **思路**：最后一步只可能来自 \(n-1\) 或 \(n-2\)，所以 \(f_n=f_{n-1}+f_{n-2}\)。只保留最近两个状态即可。

    **复杂度**：时间 \(O(n)\)，额外空间 \(O(1)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int climbStairs(int n) {
            int a=0,b=1;
            while(n--){int c=a+b;a=b;b=c;}
            return b;
        }
    };
    ```
