??? problem "LeetCode 312 · 戳气球"
    [打开原题 ↗](https://leetcode.cn/problems/burst-balloons/){ .problem-source }

    **题意**：戳破一个气球可得到它与当前左右相邻气球数值的乘积，求戳完所有气球能够获得的最大硬币数。

    **思路**：正向决定“先戳谁”时邻居不断变化；反过来枚举开区间 \((l,r)\) 中最后被戳的气球 \(k\)，此时其邻居必为 \(l,r\)。区间 DP 转移为 \(dp[l][r]=\max(dp[l][k]+a_l a_k a_r+dp[k][r])\)。

    **复杂度**：时间 \(O(n^3)\)，空间 \(O(n^2)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int maxCoins(vector<int>& nums) {
            int n=nums.size();
            vector<int> a(n+2,1);
            copy(nums.begin(),nums.end(),a.begin()+1);
            vector dp(n+2,vector<int>(n+2));
            for(int len=2;len<=n+1;len++) for(int l=0,r=l+len;r<=n+1;l++,r++) for(int k=l+1;k<r;k++) dp[l][r]=max(dp[l][r],dp[l][k]+a[l]*a[k]*a[r]+dp[k][r]);
            return dp[0][n+1];
        }
    };
    ```
