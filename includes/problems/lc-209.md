??? problem "LeetCode 209 · 长度最小的子数组"
    [打开原题 ↗](https://leetcode.cn/problems/minimum-size-subarray-sum/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：求正整数数组中元素和至少为 `target` 的最短非空连续子数组长度。

    **思路**：正数保证右端扩张时窗口和不减、左端收缩时不增。每加入一个右端点，就持续删除仍能保持达标的最左元素并更新最短长度。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int minSubArrayLen(int target, vector<int>& nums) {
        int answer = nums.size() + 1;
        int left = 0;
        long long sum = 0;
        for (int right = 0; right < static_cast<int>(nums.size()); ++right) {
          sum += nums[right];
          while (sum >= target) {
            answer = min(answer, right - left + 1);
            sum -= nums[left++];
          }
        }
        return answer == static_cast<int>(nums.size()) + 1 ? 0 : answer;
      }
    };
    ```
