??? problem "LeetCode 179 · 最大数"
    [打开原题 ↗](https://leetcode.cn/problems/largest-number/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：重排非负整数并拼接，使所得十进制字符串最大。

    **思路**：相邻两段 $a,b$ 的优先级只由 $a+b$ 与 $b+a$ 的字典序决定；按此前置关系排序即可消除所有逆序对。

    **复杂度**：设总位数为 $L$，排序比较总时间 $O(L\log n)$ 量级，输出空间 $O(L)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      string largestNumber(vector<int>& nums) {
        vector<string> values;
        values.reserve(nums.size());
        for (int value : nums) {
          values.push_back(to_string(value));
        }
        sort(values.begin(), values.end(),
            [](const string& a, const string& b) { return a + b > b + a; });
        if (values[0] == "0") {
          return "0";
        }
        string answer;
        for (const string& value : values) {
          answer += value;
        }
        return answer;
      }
    };
    ```
