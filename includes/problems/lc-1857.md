??? problem "LeetCode 1857 · 有向图中最大颜色值"
    [打开原题 ↗](https://leetcode.cn/problems/largest-color-value-in-a-directed-graph/){ .problem-source }

    **题意**：每个节点带一种颜色，求所有合法路径中某一种颜色出现次数的最大值；若图中存在环则返回 \(-1\)。

    **思路**：拓扑排序同时做 DP。`dp[u][c]` 表示到达 \(u\) 的路径中颜色 \(c\) 的最大计数；节点出队时计入自身颜色，再把 26 种计数逐项传播给后继。未能拓扑处理完全部节点即存在环。

    **复杂度**：时间 \(O(26(n+m))\)，空间 \(O(26n+m)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int largestPathValue(string colors,vector<vector<int>>& edges) {
            int n=colors.size(),cnt=0,ans=0;
            vector<vector<int>> g(n);
            vector<int> in(n);
            vector<array<int,26>> dp(n);
            for(auto& e:edges) g[e[0]].push_back(e[1]),in[e[1]]++;
            queue<int> q;
            for(int i=0;i<n;i++) if(!in[i]) q.push(i);
            while(!q.empty()){
                int u=q.front();
                q.pop();
                cnt++;
                dp[u][colors[u]-'a']++;
                ans=max(ans,*max_element(dp[u].begin(),dp[u].end()));
                for(int v:g[u]){
                    for(int c=0;c<26;c++) dp[v][c]=max(dp[v][c],dp[u][c]);
                    if(!--in[v]) q.push(v);
                }
            }
            return cnt==n?ans:-1;
        }
    };
    ```
