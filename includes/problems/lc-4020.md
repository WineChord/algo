??? problem "LeetCode 4020：电梯请求 I"
    [打开原题 ↗](https://leetcode.cn/problems/elevator-requests-i/){ .problem-source }

    **难度与竞赛分**：简单；第 189 场双周赛 Q1 官方分值 3；ZeroTracer 社区估算竞赛分未知（2026-08-22）

    **题意**：电梯从 0 层出发，以每秒一层的速度按给定顺序服务楼层请求，求完成全部请求的总移动时间。

    **思路**：服务顺序固定，每一段的起点就是上一请求楼层；总时间是从初始 0 层开始的相邻楼层绝对差之和。

    **复杂度**：时间 $O(m)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int elevatorRequests(int n, vector<int>& requests) {
        static_cast<void>(n);
        int answer = 0;
        int floor = 0;
        for (int target : requests) {
          answer += abs(target - floor);
          floor = target;
        }
        return answer;
      }
    };
    ```
