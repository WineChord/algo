??? problem "LeetCode 155 · 最小栈"
    [打开原题 ↗](https://leetcode.cn/problems/min-stack/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：实现支持压栈、弹栈、读栈顶和常数时间读最小值的栈。

    **思路**：每个栈层同时保存当前值与截至该层的前缀最小值；弹栈天然恢复上一版本的聚合信息。

    **复杂度**：每个操作 $O(1)$，空间 $O(n)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class MinStack {
      vector<pair<int, int>> data;
    public:
      MinStack() = default;
      void push(int val) {
        int minimum = data.empty() ? val : min(val, data.back().second);
        data.push_back({val, minimum});
      }
      void pop() {
        data.pop_back();
      }
      int top() {
        return data.back().first;
      }
      int getMin() {
        return data.back().second;
      }
    };
    ```
