??? problem "LeetCode 104 · 二叉树的最大深度"
    [打开原题 ↗](https://leetcode.cn/problems/maximum-depth-of-binary-tree/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：返回二叉树从根到最远叶子的最长节点数，空树深度为 0。

    **思路**：BFS 每轮固定当前队列长度并完整消费一层；层数就是已经确认的深度。

    **复杂度**：时间 $O(n)$，额外空间 $O(w)$。

    **C++ 实现**

    <!-- compile:leetcode-tree -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int maxDepth(TreeNode* root) {
        if (!root) {
          return 0;
        }
        queue<TreeNode*> nodes;
        nodes.push(root);
        int depth = 0;
        while (!nodes.empty()) {
          int levelSize = nodes.size();
          ++depth;
          while (levelSize--) {
            TreeNode* node = nodes.front();
            nodes.pop();
            if (node->left) {
              nodes.push(node->left);
            }
            if (node->right) {
              nodes.push(node->right);
            }
          }
        }
        return depth;
      }
    };
    ```
