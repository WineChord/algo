??? problem "LeetCode 372 · 超级次方"
    [打开原题 ↗](https://leetcode.cn/problems/super-pow/){ .problem-source }

    **题意**：指数以十进制数字数组给出，求 $a^b\bmod 1337$。

    **思路**：从高位到低位读取指数。若已经处理的前缀是 $p$，加入新数字 $d$ 后指数变为 $10p+d$，因此答案更新为 $ans^{10}\cdot a^d\bmod 1337$；两次幂都用快速幂。

    **复杂度**：设指数有 $m$ 位，时间 $O(m)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
        int qpow(int a,int b){
            int r=1;
            for(;b;b>>=1,a=a*a%1337) if(b&1) r=r*a%1337;
            return r;
        }
    public:
        int superPow(int a,vector<int>& b) {
            int ans=1;
            a%=1337;
            for(int d:b) ans=qpow(ans,10)*qpow(a,d)%1337;
            return ans;
        }
    };
    ```
