??? problem "LeetCode 41 · 缺失的第一个正数"
    [打开原题 ↗](https://leetcode.cn/problems/first-missing-positive/){ .problem-source }

    **难度与分值**：LeetCode 官方「困难」。

    **题意**：在未排序整数数组中找出没有出现的最小正整数，要求线性时间和常数额外空间。

    **思路**：答案只可能位于 $[1,n+1]$。把每个合法值 $x$ 原地换到下标 $x-1$；完成后第一个不匹配的槽位就是答案。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int firstMissingPositive(vector<int>& nums) {
        int n = nums.size();
        for (int i = 0; i < n; ++i) {
          while (1 <= nums[i] && nums[i] <= n && nums[nums[i] - 1] != nums[i]) {
            swap(nums[i], nums[nums[i] - 1]);
          }
        }
        for (int i = 0; i < n; ++i) {
          if (nums[i] != i + 1) {
            return i + 1;
          }
        }
        return n + 1;
      }
    };
    ```
