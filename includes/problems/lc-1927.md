??? problem "LeetCode 1927：求和游戏"
    [打开原题 ↗](https://leetcode.cn/problems/sum-game/){ .problem-source }

    **难度与竞赛分**：中等；第 56 场双周赛 Q3 官方分值 5；ZeroTracer 社区估算竞赛分 2004.535（2026-08-23）

    **题意**：Alice 与 Bob 轮流把数字串中的问号替换为 0–9，Alice 先手；最终两半数位和不等时 Alice 胜，相等时 Bob 胜。判断双方最优时 Alice 是否必胜。

    **思路**：统计已知左右和差 $\Delta=L-R$ 与左右问号数 $q_L,q_R$。问号总数为奇数时 Alice 多一步而必胜；总数为偶数时，Bob 恰能守平当且仅当 $2\Delta=9(q_R-q_L)$。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      bool sumGame(string num) {
        int half = static_cast<int>(num.size()) / 2;
        int difference = 0;
        int leftQuestions = 0;
        int rightQuestions = 0;
        for (int i = 0; i < static_cast<int>(num.size()); ++i) {
          if (num[i] == '?') {
            if (i < half) {
              ++leftQuestions;
            } else {
              ++rightQuestions;
            }
          } else {
            difference += (i < half ? 1 : -1) * (num[i] - '0');
          }
        }
        if ((leftQuestions + rightQuestions) % 2 == 1) return true;
        return 2 * difference != 9 * (rightQuestions - leftQuestions);
      }
    };
    ```
