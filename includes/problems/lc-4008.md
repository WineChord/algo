??? problem "LeetCode 4008 · 击败所有怪物的最小初始强度"
    [打开原题 ↗](https://leetcode.cn/problems/minimum-initial-strength-to-defeat-all-monsters/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」，第 188 场双周赛官方 5 分；ZeroTracer 社区估算竞赛分未知（核对于 2026-08-12）。

    **题意**：按固定顺序击败怪物，区间增强会降低对应位置所需的初始强度；求能完成全部战斗的最小初始强度。

    **思路**：用区间差分求每只怪物获得的总增强。若增强不足以覆盖当前怪物，初始强度必须至少为此前消耗前缀加当前缺口；扫描所有位置取最大下界。

    **复杂度**：时间 O(n+q)，空间 O(n)。

    **C++ 实现**

    <!-- compile:standalone -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      long long minInitialStrength(vector<int>& monsters, vector<vector<int>>& boosts) {
        int n = monsters.size();
        vector<long long> difference(n + 1);
        for (const auto& boost : boosts) {
          difference[boost[0]] += boost[2];
          difference[boost[1] + 1] -= boost[2];
        }
        long long bonus = 0, defeated = 0, answer = 0;
        for (int i = 0; i < n; ++i) {
          bonus += difference[i];
          if (bonus < monsters[i]) {
            answer = max(answer, defeated + monsters[i] - bonus);
          }
          defeated += monsters[i];
        }
        return answer;
      }
    };
    int main() {
      vector<int> monsters{5, 10, 15};
      vector<vector<int>> boosts{{1, 1, 10}};
      cout << Solution().minInitialStrength(monsters, boosts) << '\n';
    }
    ```
