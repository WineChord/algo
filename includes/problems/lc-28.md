??? problem "LeetCode 28 · 找出字符串中第一个匹配项的下标"
    [打开原题 ↗](https://leetcode.cn/problems/find-the-index-of-the-first-occurrence-in-a-string/){ .problem-source }

    **题意**：返回模式串 `needle` 在文本串 `haystack` 中第一次出现的起始下标，不存在则返回 $-1$。

    **思路**：KMP 先计算模式串的前缀函数。失配时，不回退文本指针，而是把已经匹配的长度跳到“最长相等真前后缀”，从而复用已知匹配信息。

    **复杂度**：时间 $O(n+m)$，空间 $O(m)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int strStr(string s,string p) {
            int m=p.size();
            if(!m) return 0;
            vector<int> pi(m);
            for(int i=1,j=0;i<m;i++){
                while(j&&p[i]!=p[j]) j=pi[j-1];
                if(p[i]==p[j]) j++;
                pi[i]=j;
            }
            for(int i=0,j=0;i<(int)s.size();i++){
                while(j&&s[i]!=p[j]) j=pi[j-1];
                if(s[i]==p[j]) j++;
                if(j==m) return i-m+1;
            }
            return -1;
        }
    };
    ```
