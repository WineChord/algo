??? problem "LeetCode 3286 · 穿越网格图的安全路径"
    [打开原题 ↗](https://leetcode.cn/problems/find-a-safe-walk-through-a-grid/){ .problem-source }

    **题意**：在二值网格中四向移动，进入值为 1 的格子损失 1 点健康；起点也计费。判断能否在健康始终严格为正时到达右下角。

    **思路**：把进入格子的值看作边权 0/1，用 0-1 BFS 求起点到终点的最小损失；最小损失严格小于 `health` 时可行。

    **复杂度**：时间 $O(mn)$，空间 $O(mn)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      bool findSafeWalk(vector<vector<int>>& grid, int health) {
        int m = grid.size(), n = grid[0].size();
        const int inf = 1e9;
        vector<vector<int>> dist(m, vector<int>(n, inf));
        deque<pair<int, int>> queue;
        dist[0][0] = grid[0][0];
        queue.push_front({0, 0});
        const int dx[4] = {1, -1, 0, 0};
        const int dy[4] = {0, 0, 1, -1};
        while (!queue.empty()) {
          auto [x, y] = queue.front();
          queue.pop_front();
          for (int d = 0; d < 4; ++d) {
            int nx = x + dx[d], ny = y + dy[d];
            if (nx < 0 || nx >= m || ny < 0 || ny >= n) continue;
            int nextDistance = dist[x][y] + grid[nx][ny];
            if (nextDistance >= dist[nx][ny]) continue;
            dist[nx][ny] = nextDistance;
            if (grid[nx][ny] == 0) queue.push_front({nx, ny});
            else queue.push_back({nx, ny});
          }
        }
        return dist[m - 1][n - 1] < health;
      }
    };
    ```
