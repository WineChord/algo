??? problem "LeetCode 560 · 和为 K 的子数组"
    [打开原题 ↗](https://leetcode.cn/problems/subarray-sum-equals-k/){ .problem-source }

    **题意**：统计元素和恰好为 `k` 的连续子数组数量。

    **思路**：若当前前缀和为 `s`，此前每个值为 `s-k` 的前缀都对应一个合法子数组。用哈希表维护已出现前缀和的次数。

    **复杂度**：期望时间 \(O(n)\)，额外空间 \(O(n)\)。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int subarraySum(vector<int>& a, int k) {
            unordered_map<int, int> cnt{{0, 1}};
            int ans = 0, s = 0;
            for (int x : a) {
                s += x;
                if (cnt.count(s - k)) ans += cnt[s - k];
                ++cnt[s];
            }
            return ans;
        }
    };
    ```
