??? problem "LeetCode 560 · 和为 K 的子数组"
    [打开原题 ↗](https://leetcode.cn/problems/subarray-sum-equals-k/){ .problem-source }

    **难度**：LeetCode 官方「中等」。

    **题意**：统计元素和恰好为 `k` 的连续非空子数组数量。

    **思路**：若当前前缀和为 `prefix`，此前每个值为 `prefix-k` 的前缀都对应一个合法子数组。哈希表保存历史前缀和频次；初始空前缀频次为 1，并保持先查询、后插入。

    **复杂度**：期望时间 $O(n)$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int subarraySum(vector<int>& nums, int k) {
        unordered_map<long long, int> frequency;
        frequency.reserve(nums.size() * 2 + 1);
        frequency[0] = 1;
        long long prefix = 0;
        int answer = 0;
        for (int value : nums) {
          prefix += value;
          auto it = frequency.find(prefix - k);
          if (it != frequency.end()) answer += it->second;
          ++frequency[prefix];
        }
        return answer;
      }
    };
    ```
