??? problem "LeetCode 2996 · 大于等于顺序前缀和的最小缺失整数"
    [打开原题 ↗](https://leetcode.cn/problems/smallest-missing-integer-greater-than-sequential-prefix-sum/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」，2026-08-11 力扣中国每日一题。

    **题意**：求数组从首项开始、相邻值每次恰增一的最长前缀之和，再返回不小于该和且未在数组出现的最小整数。

    **思路**：一次扫描确定顺序前缀和；由原题短值域建立出现表，从该和开始向上找到第一个缺失值。

    **复杂度**：时间 $O(n+U)$，空间 $O(U)$；原题下 $U$ 为常数级短值域。

    **C++ 实现**

    <!-- compile:standalone -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int missingInteger(vector<int>& nums) {
        int sum = nums[0];
        for (int i = 1; i < static_cast<int>(nums.size()); ++i) {
          if (nums[i] != nums[i - 1] + 1) {
            break;
          }
          sum += nums[i];
        }
        array<bool, 51> present{};
        for (int value : nums) {
          present[value] = true;
        }
        while (sum <= 50 && present[sum]) {
          ++sum;
        }
        return sum;
      }
    };
    int main() {
      vector<int> nums{1, 2, 3, 2, 5};
      cout << Solution().missingInteger(nums) << '\n';
    }
    ```
