??? problem "LeetCode 4000 · 给定数位和的最大整数"
    [打开原题 ↗](https://leetcode.cn/problems/largest-integer-with-given-digit-sum/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」，第 512 场周赛官方 3 分；ZeroTracer 社区估算竞赛分暂无数据（检索于 2026-07-30）。

    **题意**：给定最多位数与目标数位和，返回满足条件的最大非负整数，不存在则返回 $-1$。

    **思路**：先判数位容量是否足够。最大化整数等价于按字典序最大化等长数字串，因此从最高位开始尽量放 9，再放余数，剩余低位填 0。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int largestInteger(int n, int s) {
        if (s > 9 * n) {
          return -1;
        }
        int answer = 0;
        for (int position = 0; position < n; ++position) {
          int digit = min(9, s);
          answer = answer * 10 + digit;
          s -= digit;
        }
        return answer;
      }
    };
    ```
