??? problem "LeetCode 199：二叉树的右视图"
    [打开原题 ↗](https://leetcode.cn/problems/binary-tree-right-side-view/){ .problem-source }

    **难度**：中等

    **题意**：从二叉树右侧观察，按从上到下的顺序返回每一层可见的节点值。

    **思路**：按“根、右、左”做 DFS。第一次到达深度 `depth` 时，当前节点就是该层最右节点；用 `depth == answer.size()` 判断首次到达，每层只记录一次。

    **复杂度**：时间 $O(n)$，递归空间 $O(h)$，答案空间 $O(h)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    struct TreeNode {
      int val;
      TreeNode* left;
      TreeNode* right;
      TreeNode(int value = 0, TreeNode* l = nullptr, TreeNode* r = nullptr)
          : val(value), left(l), right(r) {}
    };
    class Solution {
    public:
      vector<int> rightSideView(TreeNode* root) {
        vector<int> answer;
        visit(root, 0, answer);
        return answer;
      }
    private:
      void visit(TreeNode* node, int depth, vector<int>& answer) {
        if (!node) return;
        if (depth == static_cast<int>(answer.size())) answer.push_back(node->val);
        visit(node->right, depth + 1, answer);
        visit(node->left, depth + 1, answer);
      }
    };
    ```
