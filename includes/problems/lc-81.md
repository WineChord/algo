??? problem "LeetCode 81 · 搜索旋转排序数组 II"
    [打开原题 ↗](https://leetcode.cn/problems/search-in-rotated-sorted-array-ii/){ .problem-source }

    **题意**：允许重复元素的旋转升序数组中，判断目标值是否存在。

    **思路**：仍判断哪一半有序；当左端、中点和右端相等时无法判定旋转位置，只能同时收缩两端。

    **复杂度**：平均时间 $O(\log n)$，最坏 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        bool search(vector<int>& a, int target) {
            int l = 0, r = a.size() - 1;
            while (l <= r) {
                int m = l + (r - l) / 2;
                if (a[m] == target) return true;
                if (a[l] == a[m] && a[m] == a[r]) {
                    ++l;
                    --r;
                } else if (a[l] <= a[m]) {
                    if (a[l] <= target && target < a[m]) r = m - 1;
                    else l = m + 1;
                } else {
                    if (a[m] < target && target <= a[r]) l = m + 1;
                    else r = m - 1;
                }
            }
            return false;
        }
    };
    ```
