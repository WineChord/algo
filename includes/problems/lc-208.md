??? problem "LeetCode 208 · 实现 Trie（前缀树）"
    [打开原题 ↗](https://leetcode.cn/problems/implement-trie-prefix-tree/){ .problem-source }

    **题意**：实现字符串插入、完整单词查询和前缀查询三种操作。

    **思路**：Trie 的每条边代表一个字符，从根到节点的路径代表一个前缀。插入时按需创建节点，完整单词的末节点额外标记 `end`；前缀查询不要求该标记。

    **复杂度**：每次操作时间 $O(L)$，总空间 $O(\sum L)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Trie {
        struct Node{int ch[26]{};bool end=false;};
        vector<Node> t;
        int walk(const string& s){
            int u=0;
            for(char c:s){
                u=t[u].ch[c-'a'];
                if(!u) return -1;
            }
            return u;
        }
    public:
        Trie():t(1){}
        void insert(string word) {
            int u=0;
            for(char c:word){
                int x=c-'a';
                if(!t[u].ch[x]) t[u].ch[x]=t.size(),t.push_back({});
                u=t[u].ch[x];
            }
            t[u].end=true;
        }
        bool search(string word) {
            int u=walk(word);
            return u>=0&&t[u].end;
        }
        bool startsWith(string prefix) {
            return walk(prefix)>=0;
        }
    };
    ```
