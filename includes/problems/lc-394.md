??? problem "LeetCode 394 · 字符串解码"
    [打开原题 ↗](https://leetcode.cn/problems/decode-string/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：把可嵌套的 `k[encoded_string]` 编码完整展开为原字符串。

    **思路**：遇到左括号时保存父层字符串与重复次数，遇到右括号时展开当前层并接回父层。

    **复杂度**：设解码后长度为 $L$，时间 $O(L)$，空间 $O(L+d)$，其中 $d$ 为嵌套深度。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      string decodeString(string s) {
        vector<pair<string, int>> stack;
        string current;
        int repeat = 0;
        for (char character : s) {
          if (isdigit(static_cast<unsigned char>(character))) {
            repeat = repeat * 10 + character - '0';
          } else if (character == '[') {
            stack.push_back({std::move(current), repeat});
            current.clear();
            repeat = 0;
          } else if (character == ']') {
            auto [parent, times] = std::move(stack.back());
            stack.pop_back();
            parent.reserve(parent.size() + current.size() * times);
            for (int copy = 0; copy < times; ++copy) {
              parent += current;
            }
            current = std::move(parent);
          } else {
            current.push_back(character);
          }
        }
        return current;
      }
    };
    ```
