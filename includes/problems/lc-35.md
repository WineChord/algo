??? problem "LeetCode 35 · 搜索插入位置"
    [打开原题 ↗](https://leetcode.cn/problems/search-insert-position/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：在严格升序数组中返回目标值下标，或保持有序的插入位置。

    **思路**：答案就是第一个不小于目标的位置。维护半开区间 $[l,r)$，中点满足条件时保留左半，否则排除中点及其左侧。

    **复杂度**：时间 $O(\log n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int searchInsert(vector<int>& nums, int target) {
        int left = 0;
        int right = nums.size();
        while (left < right) {
          int middle = left + (right - left) / 2;
          if (nums[middle] < target) {
            left = middle + 1;
          } else {
            right = middle;
          }
        }
        return left;
      }
    };
    ```
