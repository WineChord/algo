??? problem "LeetCode 1872：石子游戏 VIII"
    [打开原题 ↗](https://leetcode.cn/problems/stone-game-viii/){ .problem-source }

    **难度与竞赛分**：困难；第 242 场周赛 Q4 官方分值 6；ZeroTracer 社区估算竞赛分 2439.734（2026-08-24）

    **题意**：双方轮流把当前最左边至少两颗石子合并成其价值和，并把该和计入自己得分；只剩一颗时结束。求最优策略下先手与后手的最终分差。

    **思路**：任一局面都由已经合并到的原数组前缀唯一描述。把数组原地改成前缀和；从右向左维护后继状态的最大分差 `best`，当前前缀要么继续采用后继最优值，要么立即取得当前前缀和并把后继优势交给对手，即 `best = max(best, prefix - best)`。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int stoneGameVIII(vector<int>& stones) {
        int n = stones.size();
        for (int i = 1; i < n; ++i) {
          stones[i] += stones[i - 1];
        }
        int best = stones[n - 1];
        for (int i = n - 2; i >= 1; --i) {
          best = max(best, stones[i] - best);
        }
        return best;
      }
    };
    ```
