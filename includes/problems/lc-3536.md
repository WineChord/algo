??? problem "LeetCode 3536 · 两个数字的最大乘积"
    [打开原题 ↗](https://leetcode.cn/problems/maximum-product-of-two-digits/){ .problem-source }

    **题意**：把正整数拆成十进制数位，从不同位置选择两个数位，使乘积最大；同一个数字若出现多次，可以按其出现次数选取。

    **思路**：数位都非负，因此最优答案一定由最大的两个数位出现组成。扫描数位时维护当前最大值 `a` 和次大值 `b`；更新最大值时把旧的 `a` 下放给 `b`，并用 `>=` 正确保留重复数位。

    **复杂度**：设数位数为 $d$，时间 $O(d)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int maxProduct(int n) {
        int a = -1, b = -1;
        while (n) {
          int x = n % 10;
          if (x >= a) {
            b = a;
            a = x;
          } else if (x > b) {
            b = x;
          }
          n /= 10;
        }
        return a * b;
      }
    };
    ```
