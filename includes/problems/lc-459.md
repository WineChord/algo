??? problem "LeetCode 459 · 重复的子字符串"
    [打开原题 ↗](https://leetcode.cn/problems/repeated-substring-pattern/){ .problem-source }

    **题意**：判断字符串能否由某个非空子串重复若干次构成。

    **思路**：设字符串长度为 $n$，前缀函数末值为 $l$，则候选最小周期为 $p=n-l$。只有 $l>0$ 且 $p\mid n$ 时，整个字符串才能由长度为 $p$ 的块重复组成。

    **复杂度**：时间 $O(n)$，空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        bool repeatedSubstringPattern(string s) {
            int n=s.size();
            vector<int> pi(n);
            for(int i=1,j=0;i<n;i++){
                while(j&&s[i]!=s[j]) j=pi[j-1];
                if(s[i]==s[j]) j++;
                pi[i]=j;
            }
            int p=n-pi.back();
            return pi.back()&&n%p==0;
        }
    };
    ```
