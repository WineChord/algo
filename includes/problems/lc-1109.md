??? problem "LeetCode 1109 · 航班预订统计"
    [打开原题 ↗](https://leetcode.cn/problems/corporate-flight-bookings/){ .problem-source }

    **题意**：多次给一段连续航班编号增加预订座位数，求每个航班最终的预订总数。

    **思路**：对每次区间加法只修改差分数组的起点和终点后一位，最后求一次前缀和恢复所有位置。

    **复杂度**：时间 $O(n+q)$，额外空间 $O(n)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        vector<int> corpFlightBookings(vector<vector<int>>& b, int n) {
            vector<int> d(n + 1);
            for (auto& v : b) {
                d[v[0] - 1] += v[2];
                d[v[1]] -= v[2];
            }
            d.resize(n);
            partial_sum(d.begin(), d.end(), d.begin());
            return d;
        }
    };
    ```
