??? problem "LeetCode 977 · 有序数组的平方"
    [打开原题 ↗](https://leetcode.cn/problems/squares-of-a-sorted-array/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：把非递减数组的每个元素平方，并返回仍按非递减顺序排列的结果。

    **思路**：平方后的最大值一定来自当前绝对值较大的端点；双指针比较两端，倒序永久定稿答案槽位。

    **复杂度**：时间 $O(n)$，除答案外额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      vector<int> sortedSquares(vector<int>& nums) {
        int left = 0;
        int right = static_cast<int>(nums.size()) - 1;
        vector<int> answer(nums.size());
        for (int write = right; write >= 0; --write) {
          if (abs(nums[left]) > abs(nums[right])) {
            answer[write] = nums[left] * nums[left];
            ++left;
          } else {
            answer[write] = nums[right] * nums[right];
            --right;
          }
        }
        return answer;
      }
    };
    ```
