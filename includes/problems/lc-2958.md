??? problem "LeetCode 2958 · 最多 K 个重复元素的最长子数组"
    [打开原题 ↗](https://leetcode.cn/problems/length-of-longest-subarray-with-at-most-k-frequency/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」，2026-08-12 力扣中国每日一题。

    **题意**：求最长连续子数组，使其中任意值的出现次数都不超过 k。

    **思路**：右端加入新值；只有该值可能违反频次上限，于是持续右移左端并同步减少计数，直到窗口重新合法，再更新最大长度。

    **复杂度**：时间 O(n)，空间 O(U)，U 为不同值数量。

    **C++ 实现**

    <!-- compile:standalone -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int maxSubarrayLength(vector<int>& nums, int k) {
        unordered_map<int, int> frequency;
        int left = 0, answer = 0;
        for (int right = 0; right < static_cast<int>(nums.size()); ++right) {
          ++frequency[nums[right]];
          while (frequency[nums[right]] > k) {
            --frequency[nums[left++]];
          }
          answer = max(answer, right - left + 1);
        }
        return answer;
      }
    };
    int main() {
      vector<int> nums{1, 2, 3, 1, 2, 3, 1, 2};
      cout << Solution().maxSubarrayLength(nums, 2) << '\n';
    }
    ```
