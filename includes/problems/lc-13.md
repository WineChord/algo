??? problem "LeetCode 13 · 罗马数字转整数"
    [打开原题 ↗](https://leetcode.cn/problems/roman-to-integer/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：把合法罗马数字转换成对应整数。

    **思路**：合法减法对的左符号值必小于右邻；扫描时遇到这种位置就减，否则加。

    **复杂度**：时间 $O(n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
      int value(char symbol) {
        if (symbol == 'I')
          return 1;
        if (symbol == 'V')
          return 5;
        if (symbol == 'X')
          return 10;
        if (symbol == 'L')
          return 50;
        if (symbol == 'C')
          return 100;
        if (symbol == 'D')
          return 500;
        return 1000;
      }
    public:
      int romanToInt(string s) {
        int answer = 0;
        for (int i = 0; i < static_cast<int>(s.size()); ++i) {
          int current = value(s[i]);
          int next = i + 1 < static_cast<int>(s.size()) ? value(s[i + 1]) : 0;
          answer += current < next ? -current : current;
        }
        return answer;
      }
    };
    ```
