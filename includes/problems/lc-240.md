??? problem "LeetCode 240 · 搜索二维矩阵 II"
    [打开原题 ↗](https://leetcode.cn/problems/search-a-2d-matrix-ii/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：矩阵每行、每列均非降，判断目标值是否出现。

    **思路**：从右上角出发：当前值过大就删掉整列，过小就删掉整行。每一步都安全排除一条边界，形成最多 $m+n$ 步的阶梯路径。

    **复杂度**：时间 $O(m+n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int row = 0;
        int column = static_cast<int>(matrix[0].size()) - 1;
        while (row < static_cast<int>(matrix.size()) && column >= 0) {
          if (matrix[row][column] == target) {
            return true;
          }
          if (matrix[row][column] > target) {
            --column;
          } else {
            ++row;
          }
        }
        return false;
      }
    };
    ```
