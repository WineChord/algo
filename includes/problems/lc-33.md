??? problem "LeetCode 33 · 搜索旋转排序数组"
    [打开原题 ↗](https://leetcode.cn/problems/search-in-rotated-sorted-array/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：在互异升序数组旋转后的结果中查找目标值，返回下标或 $-1$。

    **思路**：每轮至少有一半仍严格有序。先判断目标是否落在该有序半段的值域内，保留可能含答案的一半；否则转向另一半。

    **复杂度**：时间 $O(\log n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      int search(vector<int>& nums, int target) {
        int left = 0;
        int right = static_cast<int>(nums.size()) - 1;
        while (left <= right) {
          int middle = left + (right - left) / 2;
          if (nums[middle] == target) {
            return middle;
          }
          if (nums[left] <= nums[middle]) {
            if (nums[left] <= target && target < nums[middle]) {
              right = middle - 1;
            } else {
              left = middle + 1;
            }
          } else {
            if (nums[middle] < target && target <= nums[right]) {
              left = middle + 1;
            } else {
              right = middle - 1;
            }
          }
        }
        return -1;
      }
    };
    ```
