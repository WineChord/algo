??? problem "LeetCode 88 · 合并两个有序数组"
    [打开原题 ↗](https://leetcode.cn/problems/merge-sorted-array/){ .problem-source }

    **难度**：LeetCode 官方「简单」。

    **题意**：把两个非递减数组的有效部分原地合并到第一个数组预留的空间中。

    **思路**：从尾部比较两个数组尚未归并的最大值并写入最右空位，避免从前写时覆盖第一个数组中尚未读取的元素。

    **复杂度**：时间 $O(m+n)$，额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      void merge(vector<int>& nums1, int m, vector<int>& nums2, int n) {
        int i = m - 1;
        int j = n - 1;
        int write = m + n - 1;
        while (j >= 0) {
          if (i >= 0 && nums1[i] > nums2[j]) nums1[write--] = nums1[i--];
          else nums1[write--] = nums2[j--];
        }
      }
    };
    ```
