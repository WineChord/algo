??? problem "LeetCode 19 · 删除链表的倒数第 N 个结点"
    [打开原题 ↗](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/){ .problem-source }

    **难度与分值**：LeetCode 官方「中等」。

    **题意**：删除单链表倒数第 $n$ 个结点并返回新头结点。

    **思路**：以哨兵统一删除头结点，让快指针领先慢指针 $n+1$ 步；快指针到尾时慢指针恰在待删结点前驱。

    **复杂度**：时间 $O(L)$，额外空间 $O(1)$。

    **C++ 实现**

    <!-- compile:leetcode-list -->
    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      ListNode* removeNthFromEnd(ListNode* head, int n) {
        ListNode dummy(0, head);
        ListNode* fast = &dummy;
        ListNode* slow = &dummy;
        for (int step = 0; step <= n; ++step) {
          fast = fast->next;
        }
        while (fast != nullptr) {
          fast = fast->next;
          slow = slow->next;
        }
        slow->next = slow->next->next;
        return dummy.next;
      }
    };
    ```
