??? problem "LeetCode 1929 · 数组串联"
    [打开原题 ↗](https://leetcode.cn/problems/concatenation-of-array/){ .problem-source }

    **难度与分值**：LeetCode 官方「简单」。

    **题意**：返回由输入数组连续重复两次得到的新数组。

    **思路**：预分配长度 $2n$，读取 `nums[i]` 时同时写入 `i` 与 `i+n`，每个答案槽位一次定稿。

    **复杂度**：时间 $O(n)$，除输出数组外额外空间 $O(1)$。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
      vector<int> getConcatenation(vector<int>& nums) {
        int n = nums.size();
        vector<int> answer(2 * n);
        for (int i = 0; i < n; ++i) {
          answer[i] = nums[i];
          answer[i + n] = nums[i];
        }
        return answer;
      }
    };
    ```
