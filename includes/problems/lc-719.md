??? problem "LeetCode 719 · 找出第 K 小的数对距离"
    [打开原题 ↗](https://leetcode.cn/problems/find-k-th-smallest-pair-distance/){ .problem-source }

    **题意**：在所有下标对的绝对差中，求第 `k` 小的距离。

    **思路**：排序后，对候选距离 `d` 用双指针统计差值不超过 `d` 的数对数量；该数量随 `d` 单调不减，二分第一个达到 `k` 的距离。

    **复杂度**：时间 $O(n\log n+n\log V)$，其中 $V=\max a-\min a$；额外空间取决于排序。

    **C++ 实现**

    ```cpp
    #include <bits/stdc++.h>
    using namespace std;
    class Solution {
    public:
        int smallestDistancePair(vector<int>& a, int k) {
            sort(a.begin(), a.end());
            int l = 0, r = a.back() - a.front();
            auto count = [&](int d) {
                long long cnt = 0;
                for (int i = 0, j = 0; i < (int)a.size(); ++i) {
                    while (a[i] - a[j] > d) ++j;
                    cnt += i - j;
                }
                return cnt;
            };
            while (l < r) {
                int m = l + (r - l) / 2;
                if (count(m) >= k) r = m;
                else l = m + 1;
            }
            return l;
        }
    };
    ```
